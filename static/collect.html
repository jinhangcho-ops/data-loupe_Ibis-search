2. 받는 방식

3. env 파일

값은 저장하지 않고 경로만 저장합니다. 요청에는 {env:이름}으로 씁니다.

4. 쪽 넘기기

5. 받는 속도

쪽 번호·offset 방식만 동시에 받습니다.
웹페이지는 수집용 창 하나로 받습니다. 간격은 쪽 사이, 시간 초과는 쪽 하나를 여는 시간입니다.

6. 사용 한도

비우면 제한 없음. 이름을 비우고 저장하면 고른 묶음에 덮어씁니다.

7. 저장

중복 기준 컬럼 (선택, 쉼표로 구분). 값이 모두 같은 행은 하나만 남깁니다.

요청 예시 붙여 넣기

curl 명령, HTTP 요청, JSON 중 하나를 붙여 넣고 [읽기]를 누르면 아래 칸을 채웁니다. 붙여 넣은 글은 저장하지 않습니다.

비밀처럼 보이는 값

env 이름을 고르고 [env 이름으로 바꾸기]를 누르면 값 대신 {env:이름}이 들어갑니다. 비밀이 아니면 ×로 뺍니다.
