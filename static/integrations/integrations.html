어떤 걸 하실 건가요?

Data Loupe를 다른 서비스와 이어요. 결과를 Slack이나 Notion으로 보내고, Slack 질문에 답하고, GA4 데이터를 가져오고, LLM으로 SQL을 만들 수 있어요. 토큰과 키는 서비스마다 고른 방법으로만 보관해요.

  • 결과를 Slack·Notion으로 보내기

    알림, 집계 표, 차트를 팀이 보는 곳으로 보내요.

  • Slack에서 물어보기

    Slack에서 /ibis 명령으로 저장한 검색과 지표를 물어봐요.

  • 웹사이트 방문 데이터 받기

    GA4 보고서를 파일로 받아 쿼리나 분석 화면에서 열어요.

  • 질문으로 SQL 만들기

    말로 물으면 SQL을 만들어 주는 AI(LLM)를 정해요.

결과 보내기

알림, 집계 표, 차트를 다른 서비스로 보내요. 보낼 수 있는 곳:

    Slack 봇

    Slack에서 /ibis 명령으로 저장한 검색과 지표를 물어볼 수 있어요. 질문을 보내면 SQL을 만들어 주지만, 그 SQL을 실행하지는 않아요.

    Google Analytics 4

    웹사이트 방문 데이터(GA4 보고서)를 파일로 받아 쿼리나 분석 화면에서 열어요.
    설정하기
    보고서는 Parquet 파일로 저장해요. 서비스 계정 JSON 파일(Google이 주는 열쇠 파일)은 위치만 저장해요.

    LLM

    말로 물으면 SQL을 만들어 주는 AI(LLM)를 정해요.
    설정하기
    비밀 키 파일(env)의 위치만 저장하고, API 키는 물어볼 때마다 그 파일에서 읽어요. 데이터 값은 보내지 않아요.

    업로드 기록

    수집이나 GA4로 저장하고 올린 데이터의 크기와 범위, 지우는 명령은 수집 화면의 업로드 기록에서 볼 수 있어요.
