# 임시 저장과 이어서 하기

앱이 갑자기 꺼져도 만들던 화면을 잃지 않도록, 아래 세 화면은 바뀐 뒤 2초 동안 조용하면 상태를 `%APPDATA%\DataLoupe\drafts\`에 화면마다 파일 하나로 저장합니다.

| 화면 | 담는 것 | 지워지는 때 |
|---|---|---|
| 쿼리 (`search.json`) | 검색 조건(단계 카드·흐름·문장 보기), 작성 중인 문장(고른 틀·빈칸·기간) | 결과 파일 내보내기, SQL 결과 내보내기, 전처리로 보내기, 가상 테이블 저장, 질문 묶음 저장 |
| 분석 (`prep.json`) | 전처리 단계(컬럼 정리·거르기·계산 컬럼 등)와 입력한 값 | 전처리 [실행]으로 결과를 저장했을 때 |
| 대시보드 (`dashboard.json`) | 저장하지 않은 편집(카드·배치·팔레트·북극성) | [저장]이 성공했을 때. 보통은 자동 저장이 바로 해서 남지 않고, 저장이 안 될 때만 남습니다 |

결과 데이터의 행과 비밀번호는 담지 않고, 연결은 이름(예: `sales.duckdb`)과 비밀번호 없는 열쇠만 함께 적습니다. 1MB를 넘으면 저장하지 않고, 깨진 파일은 없는 것으로 봅니다. 정상 종료로는 지워지지 않습니다(아직 끝내지 않은 작업이므로).

## 다시 열었을 때

화면을 열면(쿼리·분석은 연결한 뒤) 남은 초안이 있을 때 팝업이 뜹니다: "이전에 편집하던 내용이 남아 있어요 (10/23 15:40, 연결: 이름)".

- **이어서 하기**: 같은 연결이면 그 화면에 되살립니다. 지금 연결에 없는 컬럼이 있으면 그 이유를 그대로 알립니다.
- **버리기**: 초안을 지웁니다.
- **다른 연결의 초안이면**: 연결 이름을 알려 주고 [닫기]만 할 수 있습니다(초안은 남음). 그 연결로 바꾼 뒤 화면을 다시 열면 이어서 할 수 있습니다. 그 전에 새로 편집을 시작하면 새 내용이 초안을 덮어씁니다.
