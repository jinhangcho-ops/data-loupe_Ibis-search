# 지표 사전: 게임 경제·이커머스·실험

[← README](../README.md) · [쿼리](query.md) · [분석](analysis.md) · [대시보드](dashboard.md) · [설정과 참고](settings.md)

**한 줄 요약**: 게임 경제·이커머스·실험·모델 지표의 식과 필요한 컬럼입니다. 쓰는 법은 [지표 사전](metrics_catalog.md) 첫 문서에 있습니다.

## 게임 경제 (12개)

재화 변화량은 얻으면 +, 쓰면 −로 적힌 컬럼이다.

| 지표 | 식 | 필요한 컬럼 |
|---|---|---|
| 재화 공급 (Faucet) | 재화 변화량 > 0의 합 | 재화 변화량 |
| 재화 소비 (Sink) | −재화 변화량 < 0의 합 | 재화 변화량 |
| 순 유입 (Net Flow) | Faucet − Sink | 재화 변화량 |
| 소비 대 공급 비율 (Sink-to-Faucet Ratio) | Sink ÷ Faucet | 재화 변화량 |
| 활성 통화량 (Active Money Supply) | 활성 사용자의 마지막 잔액 합 | 사용자·시각·잔액 |
| 화폐 유통 속도 (Velocity of Money) | Sink ÷ 활성 통화량 | 사용자·시각·재화 변화량·잔액 |
| 지니 계수 (Gini Coefficient) | (2Σ i·x(i)) ÷ (nΣx) − (n+1)/n | 값 |
| 스테이지 클리어율 (Stage Clear Rate) | 클리어 ÷ 도전 | 스테이지·결과 |
| 스테이지 도전 횟수 (Stage Try Count) | 도전 수 ÷ 도전한 (사용자, 스테이지) 수 | 스테이지·결과·사용자 |
| 선택률 (Meta Pick Rate) | 항목 선택 수 ÷ 전체 선택 수 | 항목·결과 |
| 승률 (Meta Win Rate) | 승리 ÷ 선택 | 항목·결과 |
| 천장 도달률 (Pity Reach Rate) | 천장 횟수 이상 뽑은 사용자 ÷ 뽑은 사용자 | 사용자 |

## 이커머스 (8개)

주문 컬럼이 없으면 한 행을 주문 하나로 본다.

| 지표 | 식 | 필요한 컬럼 |
|---|---|---|
| 총거래액 (GMV) | 주문 금액의 합 | 금액 |
| 수수료율 (Take Rate) | 수수료 수익 ÷ GMV | 금액·수수료 수익 |
| 평균 주문 금액 (AOV) | GMV ÷ 주문 수 | 금액 |
| 구매 빈도 (Purchase Frequency) | 주문 수 ÷ 구매자 수 | 사용자 |
| 장바구니 이탈률 (Cart Abandonment Rate) | 1 − (담은 뒤 구매한 사용자 ÷ 담은 사용자) | 사용자·시각·이벤트 |
| 검색 이탈률 (Search Exit Rate) | 검색이 마지막인 세션 ÷ 검색한 세션 | 사용자·시각·이벤트 |
| 검색 결과 없음 비율 (Zero-Result Rate) | 결과 0건 검색 ÷ 검색 | 검색 결과 수 |
| 상품 쏠림(파레토) (SKU Pareto) | 상위 p% 항목의 매출 ÷ 전체 매출 | 항목·금액 |

## 실험·모델 (14개)

유의수준·검정력은 직접 적고 정규 근사로 구한다. A/B 지표(Lift·p-value·검정력·MDE)는 함께 점검한다.

- **작은 표본**: 한 군이라도 30개 미만이거나 비율 지표의 성공·실패 기대 수가 5 미만이면 경고하고, p-value는 결론 대신 "표본이 적어 판단 보류"라고 적는다.
- **신뢰구간**: p-value 표에 차이와 Lift의 95% 신뢰구간을 함께 싣는다(Lift는 두 평균이 0보다 클 때만).
- **배정 비율 검사(SRM)**: 대조군·실험군 수가 1:1 배정에서 크게 어긋나면(p < 0.001) 배정·기록을 먼저 확인하라고 경고한다.

| 지표 | 식 | 필요한 컬럼 |
|---|---|---|
| 정밀도 (Precision) | TP ÷ (TP + FP) | 정답·예측 또는 점수 |
| 재현율 (Recall) | TP ÷ (TP + FN) | 정답·예측 또는 점수 |
| F1 점수 (F1) | 2PR ÷ (P + R) | 정답·예측 또는 점수 |
| PR 곡선 아래 넓이 (PR-AUC) | Σ (R_n − R_(n−1)) · P_n | 정답·점수 |
| 추천 순위 품질 (NDCG@K) | DCG ÷ IDCG, DCG = Σ rel_i ÷ log2(i + 1) | 질의·순위·관련도 |
| 추천 평균 정밀도 (MAP@K) | 질의별 AP@K의 평균 | 질의·순위·관련도 |
| 제곱근 평균제곱오차 (RMSE) | √ 평균((예측 − 정답)²) | 정답·예측 |
| 평균 절대 오차 (MAE) | 평균 \|예측 − 정답\| | 정답·예측 |
| 평균 절대 비율 오차 (MAPE) | 평균 \|오차 ÷ 정답\| | 정답·예측 |
| 리프트 (Lift) | (T − C) ÷ C | 실험군·지표 값 |
| 유의확률 (p-value) | 두 비율 z 검정 또는 Welch t 검정(양측) | 실험군·지표 값 |
| 검정력 (Power) | 정규 근사 검정력 | 실험군·지표 값 |
| 최소 검출 효과 (MDE) | (z_(1−α/2) + z_power) × 표준오차 | 실험군·지표 값 |
| 가드레일 (Guardrail) | Lift ≥ 한계 (또는 ≤) | 실험군·지표 값 |
