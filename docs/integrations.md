# 연동

[← README](../README.md) · [쿼리](query.md) · [분석](analysis.md) · [수집](collect.md) · [연동](integrations.md) · [설정과 참고](settings.md)

**한 줄 요약**: 이 프로그램을 회사에서 쓰는 다른 서비스(Slack, Notion, Google Analytics, AI)와 이어 주는 곳입니다. 결과를 메신저로 보내고, 메신저에서 물어보고, 다른 서비스의 데이터를 가져옵니다. **설정하지 않은 서비스로는 아무것도 보내지 않습니다.**

| 말 | 뜻 |
|---|---|
| 토큰 | 서비스가 발급하는 출입증 글자. 이걸로 프로그램이 대신 메시지를 보냄. 비밀번호처럼 다룸 |
| 봇 | 메신저 안에서 대신 말해 주는 계정 |
| 웹훅 | 정해 둔 주소로 보내면 Teams·Discord 등에 메시지가 뜨게 하는 방법 |
| GA4 / 서비스 계정 | Google Analytics 4 / 프로그램이 Google에 로그인할 때 쓰는 계정(키 파일) |

## 연동

![연동 화면](screen-integrations.png)

위쪽 [연동]을 누르면 서비스가 카드로 모여 있고, 카드마다 상태(등록 수, 켜짐, 설정 안 됨)가 보입니다.

| 서비스 | 하는 일 | 예 |
|---|---|---|
| Slack, Notion, 웹훅 | **보내기** | 오래 걸린 검색이 끝나면 Slack으로 알림, 집계 표를 Notion 페이지에 |
| Slack 봇 | **받기** | Slack에서 `/ibis 지표 매출`이라고 물으면 답함 |
| Google Analytics 4 | **가져오기** | 지난 4주 일별 방문자 수를 파일로 |
| LLM(AI) | **묻기** | "매장별 매출"이라고 쓰면 SQL을 만들어 줌([설정](query.md#질문으로-sql-만들기)) |

## 따라 해 보기

**1. 오래 걸린 작업이 끝나면 Slack으로 알림 받기**

1. Slack 앱을 만들어 봇 토큰(`xoxb-…`)과 채널 ID를 준비합니다(아래 "Slack 준비").
2. 위쪽 줄 오른쪽 **[보낼 곳]** → 이름 `팀 채널`, 종류 `Slack`, 보관 방식 `암호화해 저장`, 토큰과 채널 ID 입력.
3. **[오래 걸린 작업이 끝나면 여기로 알림]** 체크 → **[저장]** → **[시험 보내기]** 로 메시지가 오는지 확인.

이제 30초 넘게 걸린 작업이 끝나면 "검색이 끝났습니다 · orders · 1,300행 · 1분 23초"처럼 옵니다(데이터 값은 안 보냄).

**2. GA4 방문자 수를 표로 보기**

[연동] 화면 GA4 카드에 키 파일 경로, 속성 ID, 기간 `28daysAgo`~`yesterday`, 측정기준 `date`, 측정항목 `activeUsers, sessions`, 저장할 파일 `C:\data\ga4_daily.parquet` → **[저장]** → **[가져오기]** → **[쿼리로 열기]**.

**3. Slack에서 숫자 묻기**

봇을 켜 두고 Slack에서 `/ibis 지표 매출 검색="9월 정상 주문"` → `매출 (9월 정상 주문): 48,250,000` (물어본 사람에게만 보임).

## 다른 앱으로 보내기

### 보낼 곳 등록

[보낼 곳]에서 이름·종류·보관 방식을 고르고 칸을 채워 [저장]합니다. [연동 확인]은 메시지 없이 토큰만 확인하고, [시험 보내기]는 실제로 보내 봅니다. 쿼리 화면의 집계·차트 아래 [보내기]로 표와 그림을 보낼 수 있습니다(두 번 눌러야 보냄).

| 종류 | 준비 | 보낼 수 있는 것 |
|---|---|---|
| Slack | [api.slack.com](https://api.slack.com/apps)에서 앱 생성 → 권한 `chat:write`, `files:write` → 설치 → 채널에 봇 초대. `xoxb-` 토큰과 채널 ID | 글, 그림 |
| Notion | 설정 → 연결 → 통합 개발에서 토큰 발급 → 보낼 페이지의 [⋯] → 연결에 추가. 토큰과 페이지 주소 | 글, 표(페이지 끝에 덧붙임) |
| 웹훅 | 받는 서비스(Teams·Discord 등)에서 웹훅 주소 받기. [기본 틀]에서 형식 고르기 | 글, 표 |

### 비밀 값 보관 방식

| 방식 | 이럴 때 |
|---|---|
| 암호화해 저장 | 보통은 이것. 이 PC·이 Windows 계정에서만 풀림 |
| 이번 실행 동안만 | 공용 PC. 프로그램을 다시 켜면 다시 입력 |
| 환경변수 | 파일에 저장하면 안 되는 회사 규칙이 있을 때. 칸에 값 대신 변수 이름(예: `IBIS_SLACK_TOKEN`) |

### Slack 봇 (받기)

Slack에서 `/ibis` 명령으로 저장해 둔 검색·지표를 물으면 답합니다. **이 PC에서 프로그램이 켜져 있고 데이터에 연결돼 있을 때만** 답합니다.

**준비**(Slack 관리자와 함께): 앱 설정에서 Socket Mode를 켜 앱 토큰(`xapp-`)을 받고, Slash Commands에 `/ibis`를 만들고, 권한 `commands`로 설치해 봇 토큰(`xoxb-`)을 받습니다. Socket Mode라 방화벽을 열 필요가 없습니다. 쓸 사람의 멤버 ID(`U…`, 프로필 → [⋮] → 멤버 ID 복사)를 모읍니다.

**설정**: [보낼 곳] 패널 아래 "Slack 봇"에 두 토큰과 **허용할 사용자 ID**(비면 켤 수 없음)를 넣고 [저장] → [연동 확인] → [봇 시작].

| Slack에 쓰는 것 | 답 |
|---|---|
| `/ibis 도움` | 쓸 수 있는 명령 |
| `/ibis 지표` · `/ibis 검색` | 지표 목록 · 저장한 검색 목록 |
| `/ibis 지표 취소율 검색="9월 정상 주문" 나누기=매장코드` | 매장별 취소율 표 |
| `/ibis 검색 "9월 정상 주문" 행=10` | 행 수와 앞 10행 |
| `/ibis 질문 지난달 매장별 매출` | AI가 만든 SQL(실행하지 않음) |

허용하지 않은 사람에게는 쓸 수 없다고만 답하고, 데이터를 바꾸거나 SQL을 바로 실행하는 명령은 없습니다.

### Google Analytics 4 가져오기

**준비**(GA·Google Cloud 관리자에게 부탁해도 됨): Google Cloud에서 서비스 계정을 만들어 키(JSON)를 받고 "Google Analytics Data API"를 켬 → GA4 관리 → 속성 액세스 관리에 그 계정 이메일을 [뷰어]로 추가 → 속성 ID(숫자) 확인.

칸에는 키 파일 경로, 속성 ID, 기간(`2026-09-01`, `yesterday`, `28daysAgo` 등), 측정기준(무엇별로, 9개까지), 측정항목(무엇을 셀지, 10개까지), 저장할 파일을 넣습니다. [연동 확인]은 로그인만 확인하고, [가져오기]는 같은 이름 파일을 덮어쓰지 않습니다. 키 파일은 경로만 저장하고, 저장한 파일은 [업로드 기록](collect.md#업로드-기록)에 남습니다.
