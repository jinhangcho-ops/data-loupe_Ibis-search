## 쓰는 법

- 화면: [문장] 보기의 [지표] 탭 아래 **지표 사전**에서 지표를 고르면 문장이 열립니다. 빈칸(컬럼·값·상수)과 기간을 채우고 [계산]하면 지금 연결에서 구하고, [내 지표로 저장]하면 지금 테이블에 묶인 내 지표가 되어 문장·카드에서 씁니다.
- 필요한 컬럼이 없는 지표는 흐리게 두고 "광고비 컬럼이 있는 테이블이 필요해요"처럼 이유를 알려 줍니다. 컬럼 이름에 단서(spend, cost, 광고비 …)가 있으면 빈칸을 추천합니다.
- **비율 지표는 짝 절대량**(ARPPU는 결제 사용자 수와 매출, 전환율은 두 단계의 사용자 수)을, **평균형 지표는 중앙값·P90·P99**를 함께 보입니다. 북극성·카운터·가드레일 후보를 표시하며 대시보드의 북극성·카운터 한계를 그대로 씁니다. 가드레일은 실험군이 대조군보다 한계를 넘게 나빠지면 경고합니다.
- 두 테이블이 필요한 지표(CAC·ROAS·LTV:CAC·Payback)는 광고 테이블을 고르고 **기간 단위로 맞춰** 또는 **공통 키로 맞춰**를 골라야 구합니다.
- 큰 DB는 값을 읽기 전에 처리 용량을 확인하고 행 수를 미리 세지 않습니다. 파일 연결과 설정 `prep_where`가 전체인 원격 DB는 필요한 컬럼만 이 PC의 DuckDB 사본에서 구합니다. 비율은 0~1 값이고 화면이 %로 보입니다.

## 트래픽·활성도 (16개)

활동 사용자는 기간 버킷(일·주 월요일 시작·월)에서 센다. 세션은 쉰 시간이 간격(분)을 넘으면 새 세션이고, 같은 시각의 행은 한 세션이다. 사용자나 시각이 빈 행은 뺀다. 활동 없는 기간은 0명으로 평균에 넣는다. 날짜 컬럼에 아주 이른/먼 날짜가 있어 기간 칸이 활동 있는 칸의 10배를 넘으면 안내가 뜬다.

| 지표 | 식 | 필요한 컬럼 |
|---|---|---|
| 고유 사용자 수 (UV) | 고유 사용자 수 | 사용자 |
| 조회 수 (PV) | 이벤트(조회) 행 수 | 없음 |
| 사용자 1명당 조회 수 (PV/UV) | PV ÷ UV | 사용자 |
| 일간 활성 사용자 (DAU) | 일별 고유 사용자 수의 평균 | 사용자·시각 |
| 주간 활성 사용자 (WAU) | 주별 고유 사용자 수의 평균 | 사용자·시각 |
| 월간 활성 사용자 (MAU) | 월별 고유 사용자 수의 평균 | 사용자·시각 |
| 고착도 (Stickiness) | DAU ÷ MAU (×100은 %로 보일 때) | 사용자·시각 |
| 최고 동시 접속 (PCU) | 동시 접속 수의 최댓값 | 시작·끝 |
| 평균 동시 접속 (ACU) | Σ 동시 접속 × 유지 시간 ÷ 기간 길이 | 시작·끝 |
| 월 최고 동시 접속 (MCU) | 달별 동시 접속의 최댓값 | 시작·끝 |
| 사용자당 세션 수 (Session Count) | 세션 수 ÷ DAU | 사용자·시각 |
| 평균 세션 길이 (ASD) | 총 체류 시간 ÷ 세션 수 | 사용자·시각 |
| 일 체류 시간 (TSD) | 일 체류 시간 합 ÷ DAU | 사용자·시각 |
| DAU 분해 (신규·기존·복귀) | 활성 = 신규 + 기존 + 복귀 | 사용자·시각 |
| 퀵 레시오 (Quick Ratio) | (신규 + 복귀) ÷ 이탈 | 사용자·시각 |
| 파워 유저 곡선 (Power User Curve) | 사용자별 최근 L일 중 접속 일수의 분포 | 사용자·시각 |

## 퍼널·온보딩 (8개)

단계는 이벤트 컬럼의 값으로 고른다.

| 지표 | 식 | 필요한 컬럼 |
|---|---|---|
| 단계 전환율 (CVR) | B까지 간 사용자 ÷ A를 한 사용자 | 사용자·시각·이벤트 |
| 단계 이탈률 (Drop-off) | 1 − 전환율 | 사용자·시각·이벤트 |
| 이탈 세션 비율 (Bounce Rate) | 이벤트 1개짜리 세션 ÷ 세션 수 | 사용자·시각 |
| 페이지 이탈률 (Exit Rate) | 마지막 페이지가 p인 세션 ÷ p의 조회 수 | 사용자·시각·페이지 |
| 첫 가치까지 걸린 시간 (TTV/TTFV) | 사용자별 A 이후 첫 B까지의 시간 | 사용자·시각·이벤트 |
| 튜토리얼 완료율 (Tutorial Completion) | 튜토리얼 완료 사용자 ÷ 시작 사용자 | 사용자·시각·이벤트 |
| 첫 경험 퍼널 (FTUE Funnel) | 단계별 도달 사용자와 전환 | 사용자·시각·이벤트 |
| 첫 결제까지 걸린 시간 (TTFP) | 사용자별 가입 이후 첫 결제까지의 시간 | 사용자·시각·이벤트 |

## 리텐션·코호트 (7개)

코호트는 첫 활동 기간, N은 그 뒤 경과 기간이다.

| 지표 | 식 | 필요한 컬럼 |
|---|---|---|
| 클래식 리텐션 (Day-N Retention) | N일째 활동 사용자 ÷ 코호트 크기 | 사용자·시각 |
| 롤링 리텐션 (Rolling Retention) | 마지막 활동이 N 이상인 사용자 ÷ 코호트 크기 | 사용자·시각 |
| 범위 리텐션 (Bracket Retention) | [a, b] 안에 활동한 사용자 ÷ 코호트 크기 | 사용자·시각 |
| 수평 유지점 (Retention Flattening Point) | \|r(N) − r(N−1)\| < ε가 연속으로 이어지는 첫 N | 사용자·시각 |
| 이탈률 (Churn Rate) | 이탈 ÷ 앞 기간 활동자 | 사용자·시각 |
| 복귀율 (Resurrection Rate) | 복귀 ÷ 기간 시작 때 휴면자 | 사용자·시각 |
| 생존 곡선 (Survival S(t)) | Kaplan-Meier: S ×= (1 − 떠난 수 ÷ 남은 수) | 사용자·시각 |
