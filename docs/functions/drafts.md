# 임시 저장과 되돌리기

[← README](../../README.md)

## 임시 저장

앱이 갑자기 꺼져도 만들던 것을 잃지 않도록, 아래 세 화면은 바뀐 뒤 2초 동안 조용하면 상태를 `%APPDATA%\DataLoupe\drafts\`에 화면마다 파일 하나로 저장합니다. 따로 누를 단추는 없습니다.

| 화면 | 담는 것 | 지워지는 때 |
|---|---|---|
| 쿼리 (`search.json`) | 작업 탭마다의 검색 조건(단계별·문장으로 보기), 작성 중인 문장 | 결과 파일 내보내기, SQL 결과 내보내기, 전처리로 보내기, 가상 테이블 저장, 질문 묶음 저장 |
| 분석 (`prep.json`) | 전처리 단계와 입력한 값 | 전처리 [실행]으로 결과를 저장했을 때 |
| 대시보드 (`dashboard.json`) | 저장하지 못한 편집(카드·배치·카드 색·중요 지표) | 저장이 성공했을 때. 보통은 자동 저장이 바로 해서 남지 않습니다 |

- 결과 데이터의 행·카드 값과 비밀번호는 담지 않습니다. 연결은 이름(예: `shop.duckdb`)과 비밀번호 없는 열쇠만 적습니다.
- 1MB를 넘으면 저장하지 않고, 깨진 파일은 없는 것으로 봅니다. 앱을 정상 종료해도 지우지 않습니다(아직 끝내지 않은 작업이므로).

## 다시 열었을 때: 이어서 하기 창

![하던 작업을 이어서 할까요? 창: 저장한 때·화면·연결과 [버리고 새로 시작]·[이어서 하기]](../photo/drafts-restore.png)

화면을 열면(쿼리·분석은 연결한 뒤) 남은 초안이 있을 때 **"하던 작업을 이어서 할까요?"** 창이 뜹니다. 무엇이 남아 있는지 세 줄로 보여 줍니다.

| 줄 | 보이는 것 |
|---|---|
| 저장한 때 | 저장한 날짜·시각과 얼마나 됐는지. 예: `11/13 09:41 (5분 전)`. 방금·N분 전·N시간 전·N일 전으로 나옵니다 |
| 화면 | 쿼리·분석·대시보드 중 어느 화면의 작업인지 |
| 연결 | 그 작업을 하던 연결 이름(있을 때만) |

그 아래에 두 단추가 하는 일이 한 줄로 적혀 있습니다.

- **[이어서 하기]**: 그때의 조건과 설정을 화면에 다시 채웁니다. 지금 연결에 없는 컬럼이 있어 채우지 못하면 그 이유를 창에 보여 주고 단추가 **[닫기]**로 바뀝니다.
- **[버리고 새로 시작]**: 초안을 지웁니다. 지우면 되돌릴 수 없습니다.
- **다른 연결에서 하던 작업**이면 "지금과 다른 연결에서 하던 작업이에요. 그 연결로 바꾸면 이어서 할 수 있어요."라고 알리고, [이어서 하기] 대신 **[닫기]**(초안은 남음)가 나옵니다. 그 연결로 바꾼 뒤 화면을 다시 열면 이어서 할 수 있습니다. 그 전에 새로 편집하면 새 내용이 초안을 덮어씁니다.

## 되돌리기

- 대시보드, 쿼리(탐색 탭의 단계별 보기), 분석(전처리) 화면은 마지막 편집 50개까지 **Ctrl+Z**로 되돌리고 **Ctrl+Y**(또는 Ctrl+Shift+Z)로 다시 합니다. 되면 "되돌렸어요"·"다시 했어요"가 잠깐 뜹니다. 문장으로 보기에서는 되돌리지 않습니다. 예전 버전에서 흐름 그림으로 만든 초안은 그림을 빼고 단계별 보기로 엽니다.
- 글자 칸 안에서는 Ctrl+Z가 그 칸의 글자만 되돌립니다.
- 쿼리는 표를 바꿔도 되돌리기 기록이 남고(연결이 바뀔 때만 비워집니다), 전처리는 표나 저장한 설정을 열면 기록이 비워집니다.
- 되돌리지 못하면 이유가 약 4초 뜹니다.
- 창(대화상자)이나 펼친 목록이 떠 있는 동안에는 단축키가 듣지 않습니다.
- 대시보드의 카드 값은 되돌리기 대상이 아닙니다. 지운 카드를 되살리면 마지막 값으로 돌아옵니다. 차트 설정을 되돌려 값과 설정이 어긋나면, 연결돼 있으면 그 카드만 다시 구하고 아니면 카드에 "설정이 바뀌어서 값을 다시 구해야 해요." 안내가 뜹니다.
- 대시보드를 다시 열거나 최신화가 끝나 다시 열리면 되돌리기 기록이 비워집니다.
- 쿼리 화면에서 작업 탭을 닫거나 저장한 검색·SQL을 지우면 아래쪽에 5초 동안 **[되돌리기]**가 보입니다.

## 단축키

| 키 | 하는 일 |
|---|---|
| Ctrl+Z / Ctrl+Y | 되돌리기 / 다시 하기 |
| Ctrl+S | 저장(대시보드, 검색·SQL, 전처리 설정) |
| Ctrl+Enter | 실행(검색, 미리보기, 구하기, SQL) |
| Ctrl+F | 쿼리 탐색 탭의 결과 안에서 찾기 칸으로 |
| Ctrl+T / Ctrl+W | 쿼리 탐색 탭에서 새 작업 탭 / 지금 작업 탭 닫기(입력 칸 밖에서) |
| Esc | 열린 창이나 메뉴 닫기 |

쿼리 화면 위쪽의 **[단축키]** 단추가 같은 목록을 한 장으로 보여 줍니다.

화면 공유에서 "창만 공유"를 고르면 파일 저장·폴더 고르기 창은 Windows 창이라 보이지 않습니다. 화면 전체를 공유하세요.
