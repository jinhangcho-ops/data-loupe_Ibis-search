# 문장으로 보기

[← 쿼리](../query.md)

검색 조건 패널 위 **[문장으로]**를 누르면 "{무엇}별 {값}의 {집계} 상위 {N}개 보기"처럼 **빈칸이 있는 문장 틀**을 채워 묻습니다. SQL을 몰라도 됩니다. 문장은 서버가 정해진 규칙으로 요청으로 바꾸며, 데이터 값을 밖(LLM 등)으로 보내지 않습니다.

문장으로 보기 안에는 **[탐색]**(문장 틀 50개)과 **[지표]**(지표 틀 15개로 내 지표 만들기) 두 탭이 있습니다.

## 문장 틀 고르기

![왼쪽 문장 틀 50개 목록과 끌어다 놓을 컬럼 칩](../photo/sentences-templates.png)

- 왼쪽 목록에서 문장 틀을 누르면 오른쪽에 문장 카드가 더해집니다. 위 **문장 찾기** 칸에 번호나 낱말을 써서 틀을 찾습니다.
- 가운데 위의 **컬럼 칩**은 지금 테이블의 컬럼입니다. 칩 색이 숫자·날짜·글자를 나타냅니다.
- 문장을 여러 개 더해 두고 **[모두 실행]**으로 한꺼번에 돌립니다.

## 빈칸 채우기

![문장 틀 13번의 빈칸(매장·금액·합계·5)과 기간을 채운 카드](../photo/sentences-filled.png)

- 컬럼 빈칸은 **칩을 끌어다 놓거나** 빈칸을 눌러 고릅니다. 그 빈칸에 맞는 종류의 컬럼만 고를 수 있습니다.
- 집계 빈칸은 [함수 사전](sql_functions.md)의 집계에서 고르고, 단위·방향·정확도 같은 것은 누르는 단추로 고릅니다.
- 글자 컬럼은 **다듬어서** 쓸 수 있습니다: `? 뒤 자르기`·`앞 N글자`·`날짜만`·`소문자로`(사진의 **그대로** 칸).
- **기간**: 날짜 컬럼을 고르고 `최근 7일`, `이번 달`, `2026-07-01 ~ 2026-09-30`처럼 글로 씁니다. 읽은 기간이 바로 아래(`2026-07-01 ~ 2026-09-30 (92일)`)에 보이고, 읽지 못하면 이유가 나옵니다. 어느 틀이든 기간을 붙일 수 있습니다.
- 카드 아래에 완성된 문장(`매장별 금액의 합계 상위 5개 보기`)이 기울임 글씨로 보입니다. 빈칸이 잘못되면 그 칸이 표시되고 이유가 나오며, 막힌 문장은 **[실행]**이 꺼집니다.
- 상위 N은 50개까지 보여 줍니다.

## 실행과 결과

![실행 결과를 차트로 바꿔 본 모습](../photo/sentences-run.png)

- **[실행]**을 누르면 결과 문장과 표가 나옵니다. **[표 | 차트]**로 바꿔 봅니다(라벨이 날짜처럼 보이면 선, 아니면 막대, 앞 50개).
- 행을 보는 문장은 처음 1,000행, 묶어 집계하는 문장은 500행까지 보이고, 더 있으면 기간·조건을 좁히라고 알려 줍니다.
- 문장은 지금 단계별 보기의 기준 테이블·조인·조건 위에서 계산합니다.

## 질문 묶음

![질문 묶음 '9월 매장 점검': 문장 둘을 모아 저장한 모습](../photo/sentences-bundle.png)

- 문장 여러 개를 모아 위쪽에 이름(예: '9월 매장 점검')을 쓰고 **[저장]**합니다. **저장한 질문 묶음 고르기**에서 골라 다시 열고, **[삭제]**로 지웁니다.
- **모든 문장에 같은 기간 쓰기**를 켜면 기간 한 줄을 묶음 전체가 씁니다(끄면 문장마다 따로).
- 다른 테이블에서 묶음을 열면 같은 이름의 컬럼만 채우고, 없는 컬럼의 칸은 비운 뒤 어느 칸을 비웠는지 알려 줍니다.
- **[모두 실행]**은 실행할 수 있는 문장을 모두 돌립니다.

### 대시보드에 모두 추가

**[대시보드에 모두 추가]**는 어느 대시보드에 넣을지 한 번만 묻고, **묶어 집계하는 문장 하나**를 차트 카드 하나로 넣습니다. 넣지 못한 문장은 "넣지 못함, 틀 이름: 이유"로 알려 줍니다. '많은 순'으로 보는 문장은 카드도 값이 큰 순으로 그립니다.

| 넣지 않는 문장 | 이유 |
|---|---|
| 행을 보는 문장(1~5번 등) | 묶어 집계하는 문장만 차트 카드가 됩니다 |
| 여러 계산을 합쳐 구하는 문장(비율·지표 A ÷ B 등) | 카드 하나로 바로 넣을 수 없습니다 |
| 묶음을 거르는 문장: 조건(where), 집계 결과로 거르기(having), 상위 N(top) | 차트 카드에는 이 설정을 담을 칸이 없습니다 |
| 소계·총계를 붙이는 문장(subtotals) | 같은 이유 |
| 세 컬럼 이상으로 묶는 문장 | 차트 카드는 X와 나누기 두 칸뿐입니다 |
| 빈칸이 잘못된 문장 | 검사를 통과하지 못함 |

그래서 13번 "항목별 집계 상위 N개"처럼 상위 N을 거는 문장은 표로는 보이지만 카드로는 넣지 않습니다. 넣은 뒤에는 **대시보드에서 보기** 링크가 뜹니다.
