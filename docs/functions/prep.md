# 전처리

[← 분석](../analysis.md)

분석 전에 데이터를 다듬는 곳입니다. 예: `" 서울 "` → `"서울"`, `"N/A"` → 빈 값, `"20260131"` → 날짜. 왼쪽 메뉴 **[분석]**을 누르면 위쪽 **[전처리]** 탭이 먼저 열립니다. 오른쪽 **전처리 조건**의 ①~⑦을 위에서 아래로 채우고, **[미리보기]**로 확인한 뒤 **[실행]**으로 저장합니다. 원본은 바꾸지 않습니다.

| 단계 | 하는 일 |
|---|---|
| ① 데이터 | 다듬을 테이블 고르기 |
| ② 행 거르기 | 조건에 맞는 행만 남기기 |
| ③ 컬럼 정리 | 컬럼마다 빈칸 채우기·글자 고치기·타입 바꾸기·이름 바꾸기 |
| ④ 새 컬럼 | 계산식이나 PCA·K-Means·좌표로 새 컬럼 더하기 |
| ⑤ 중복 제거 | 같은 값이 여러 번 나오는 행을 하나만 남기기 |
| ⑥ 정렬 | 결과 행의 순서 정하기 |
| ⑦ 저장 | 파일로 받을지, 같은 DB의 새 테이블로 만들지 |

단계 이름을 누르면 그 단계가 펼쳐지고, 접힌 단계에는 넣어 둔 내용의 요약이 보입니다. 필요한 단계만 쓰면 됩니다. 가운데에는 **[데이터]**·**[컬럼 요약]** 탭이 있습니다.

## ① 데이터 고르기

![전처리 화면: 테이블 orders와 컬럼 정리, 미리보기 표](../photo/prep-columns.png)

- ① **데이터**에서 테이블을 고르면 가운데에 행 수와 앞 20행이 나옵니다. 연결은 **[연결 바꾸기]**로 바꿉니다.
- 표본·통계 칸은 데이터 단계의 **읽기·통계 설정**에 접혀 있고, 접힌 줄에 지금 값이 보입니다.
- **미리 읽을 행 수**(기본 5,000)만큼만 읽어 통계·추천·분석을 구합니다. 큰 테이블 대신 일부(표본)만 읽어 빠르게 보는 것입니다. 이 수는 상한이고 필요한 행 수는 먼저 작게 뽑아 본 뒤(파일럿) 정합니다. 파일(Polars) 연결은 앞·가운데·뒤 세 구간에서 나눠 읽어, 앞쪽만 치우친 표본이 되지 않게 합니다.
- **표본 방식**: 층화(Neyman, 기본)·블록(못 하면 행 단위)·키 단위 중에서 고르고, 옆에서 기준 컬럼을 고릅니다. 키 단위는 고른 키(예: 고객)의 행을 통째로 뽑고 키가 빈 행은 빠집니다. 신뢰수준·허용 오차 같은 기준은 [설정](settings.md#앱-설정)의 [표본] 분류에 있습니다.
- **통계 범위**: **표본**(기본) 또는 **전체**. 전체는 테이블 전체로 정확하게 구하지만 큰 테이블에서 오래 걸리고(요금을 받는 DB는 비용), 추천은 나오지 않습니다.
- 주소 없이 이 화면을 열면 마지막에 고른 테이블(같은 연결일 때)을 이어서 엽니다. 스키마 목록의 첫 칸은 **스키마(폴더)**입니다.
- **컬럼 통계와 추천 보기**를 끄면 데이터를 읽지 않고 컬럼 이름·타입만 봅니다.
- 주소로 연결한 DB는 **계산 위치**에서 이 PC가 계산할 범위(**전부 이 PC**, 또는 **계산 컬럼만 이 PC**)를 고릅니다. 이때 DB에는 행 거르기까지의 조회 한 번만 가고 나머지는 이 PC가 계산합니다.
- 같은 테이블을 다시 열면 지난번에 이 테이블에 쓴 전처리를 저절로 채웁니다.
- 테이블 아래 **컬럼** 목록 옆의 **+**는 방식을 골라 새 컬럼을 만드는 새 컬럼 상자를 엽니다(아래 ④ 새 컬럼).
- 쿼리 화면에서 [전처리로 보내기]로 넘어왔으면 테이블 칸 대신 "쿼리에서 넘어온 검색 '이름' · N행 · 컬럼 N개"와 **[쿼리로 돌아가기]**가 보입니다.
- **태그 붙이기**는 쿼리에서 행에 단 태그를 `태그` 컬럼으로 가져옵니다([분석](../analysis.md#전처리에-태그-붙이기)).

## ② 행 거르기

![② 행 거르기: 조건 세 줄과 미리보기로 줄어든 행 수](../photo/prep-filter.png)

조건을 한 줄씩 쓰고 Enter(또는 **[추가]**)를 누르면 맞는 행만 남깁니다. 예: `price >= 100`, `city = 서울`, `name starts 김`, `시작일 < 종료일`, `컬럼 in 값1, 값2`, `컬럼 is null`, `* is not null`(모든 컬럼에 값이 있는 행만).

조건 줄은 칩으로 쌓이고 ×로 뺍니다. 가운데 표에서 행을 고르면 나오는 **[선택한 행 빼기]**·**[선택한 행만 남기기]**도 조건 줄을 넣어 줍니다.

쿼리 화면과 같은 **[가장 많은 기간 찾기]**도 있습니다(쉬운 보기에서는 **[더 많은 설정 ▾]** 안). 날짜 타입 컬럼과 길이(1일·1주·1달)를 고르면 건수가 가장 많은 기간을 테이블 전체로 찾아(위의 조건을 건 뒤의 건수) 보여 주고, **[이 기간 적용]**이 `컬럼 between 시작 끝` 조건 줄로 넣습니다.

## ③ 컬럼 정리

가운데 표에서 컬럼 머리를 누르거나 ③에서 컬럼을 고른 뒤 **정리 방법 추가** 목록에서 방법을 더합니다. 한 컬럼에 여러 방법을 넣을 수 있고 위에서 아래 순서로 적용합니다. 위 사진은 `주문일`에 **날짜에서 뽑기**(월)를 넣어 `주문일_month` 컬럼이 새로 생긴 모습입니다. 정리한 컬럼에는 **정리함**, 새로 생긴 컬럼에는 **새 컬럼** 표시가 붙습니다.

- **결과에 남기기**를 끄면 그 컬럼을 결과에서 뺍니다. **새 이름** 칸으로 이름을 바꾸고(비우면 그대로), **[복사해서 따로 정리하기]**로 사본을 만들어 다르게 다듬을 수 있습니다(사본은 **[이 복사 컬럼 지우기]**로 지움).
- 정리 방법은 컬럼 종류에 맞는 것만 고를 수 있습니다(예: 숫자 방법은 숫자 컬럼에).

| 묶음 | 정리 방법 | 예 |
|---|---|---|
| 글자 | 앞뒤 공백 지우기 · 연속 공백을 하나로 | `' 서울 '` → `'서울'` |
| 글자 | 이 값들을 빈 값으로 | `-, N/A`를 빈 값으로(빈 문자열도 고를 수 있음) |
| 글자 | 글자 찾아 지우기 · 값 바꿔 쓰기 · 정규식으로 바꾸기 · 대문자·소문자로 | `'1,000원'`에서 `원` 지우기, `Y` → `완료` |
| 타입 | 타입 바꾸기(정수·실수·글자·날짜) | 글자 `'123'`을 숫자로, `'20260131'`을 날짜로(형식 `%Y%m%d`). 숫자는 **쉼표·단위 떼기**를 켤 수 있음 |
| 빈 값 | 빈 값 처리 · 그룹별 값으로 빈 값 채우기 | 그 행 빼기, 정한 값·평균·중앙값·최빈값·앞의 값·뒤의 값으로 채우기 / 같은 그룹 행의 평균·중앙값·최빈값으로 채우기 |
| 숫자 | 범위 밖 값 처리 | 직접 범위·사분위수(IQR)·표준편차·백분위로 정한 범위 밖을 빼거나 잘라 내기 |
| 숫자 | 거듭제곱·Box-Cox·Yeo-Johnson | 치우친 분포를 정규에 가깝게 |
| 숫자 | 크기 맞추기(스케일링) · 반올림 · 구간 나누기 · 자동으로 구간 나누기 | 표준화, 0~1·0~100 사이로, 로버스트, 로그 / 3.14159 → 3.14 / 23 → `20–30` |
| 범주 | 드문 값 묶기 · 많은 값만 남기고 묶기 | 몇 번 안 나오는 값을, 또는 많이 나온 값만 두고 나머지를 `기타`로 |
| 새 컬럼 | 컬럼 여러 개로 펼치기(구조·맵·JSON) · 목록을 행으로 펼치기 · 날짜에서 뽑기 · 빈 값 표시 컬럼 만들기 · 표시 컬럼 만들기(0·임계치·상위 %) · 값을 번호로(라벨 인코딩) · 값마다 컬럼으로(원-핫 인코딩) · 빈도 인코딩 · 타겟 인코딩 · 순서형 · 패턴에 맞는 부분 뽑기 · 글자가 들어 있는지 표시 · 단어별 개수 세기 | `주문일_month`, `'서울'`→0, 구조·맵·JSON 글자는 `컬럼.키` 컬럼들, 목록 `[사과, 배]`는 `사과`·`배` 두 행 |

새 정리 방법(고르면 한 줄 설명과 칸이 나옵니다). 비워 두면 괄호의 기본값을 씁니다.

| 정리 방법 | 하는 일 | 칸·기본값 |
|---|---|---|
| 그룹별 값으로 빈 값 채우기 | 같은 등급·연령대 행의 평균·중앙값·최빈값으로 빈칸을 채웁니다 | 묶을 컬럼 1~3개 |
| 0·임계치·상위 % 같은 표시 컬럼 만들기 | 0인지·X 이상인지·상위 1%인지 같은 0/1 컬럼을 여러 개 만듭니다(예: `금액_is_zero`, `금액_top1`) | 0이면 1 · 임계치 비교(`>=` `>` `<=` `<` `==` `!=`) · 상위 %(1·5·10) · 평균·중앙값보다 큰지 · 범위 안인지 · 값 목록에 있는지 · 이상치(IQR·Z-Score·MAD, k는 비우면 저장한 진단 기준) |
| 거듭제곱·Box-Cox·Yeo-Johnson | 치우친 분포를 정규에 가깝게 만듭니다 | 방식 · p(거듭제곱) · λ(비우면 자동으로 찾기). Box-Cox는 양수만 |
| 자동으로 구간 나누기 | 구간 글자를 자동으로 만듭니다 | 등간격 · 등빈도(분위) · 0 따로 + 양수 등빈도 · 로그 스케일 · 단위로 내림 · 양끝 묶고 가운데 등간격 · 타겟으로 최적 구간(IV 최대·카이제곱 병합). 구간 수 기본: 등간격 10, 분위 4, 0 따로 4, 양끝 10, 최적 5 · 양끝 % 5 · 경계 포함(왼쪽·오른쪽) · 구간 표시(구간 글자·가운데 값·번호) |
| 많은 값만 남기고 묶기 | 많이 나온 값만 두고 나머지는 `기타`로 묶습니다 | 많이 나온 K개(10) · 비중 X% 미만(1%) · 누적 비중 X%까지(80%) · 묶은 값의 이름 |
| 값을 등장 횟수로(빈도 인코딩) | 값을 그 값이 나온 횟수(또는 %)로 `컬럼_freq` 새 컬럼에 넣습니다 | 등장 횟수 · 비율(%) |
| 값을 타겟 평균으로(타겟 인코딩) | 값을 그 값인 행의 타겟 평균으로 새 컬럼에 넣습니다. 같은 표의 평균이라 모델을 만들면 점수가 실제보다 좋게 나올 수 있으니(누수), 학습·평가 표를 먼저 나눈 뒤 쓰라는 안내가 칸에 보입니다 | 타겟 컬럼(숫자·0/1) · 평활 m(비우면 0) |
| 정한 순서의 번호로(순서형) | `하=1, 중=2, 상=3`처럼 정한 번호를 새 컬럼에 넣습니다 | 값=번호 목록 · 목록에 없는 값의 번호(비우면 빈 값) |

기존 방법의 새 선택: **크기 맞추기**에 0~100 사이로·로버스트((x−중앙값)/IQR)·로그 log10(1+x), **범위 밖 값 처리**에 백분위로(윈저라이징, 하위·상위 % 기본 1·99), **구간 나누기**에 경계 포함(왼쪽·오른쪽)과 구간 표시(구간 글자·가운데 값·번호), **값마다 컬럼으로(원-핫)**에 많이 나온 K개만 컬럼으로 만들고 나머지는 `컬럼_기타`로 모으기.

알아 둘 규칙:

- **컬럼 여러 개로 펼치기**: 구조는 필드마다, 맵은 키마다(맵·JSON은 앞 1,000행에서 모은 키 50개까지), JSON 글자는 맨 위 키마다 `컬럼.키` 새 컬럼을 만듭니다. 찾은 키는 설정에 함께 저장해 두므로 미리보기·실행 때마다 키를 다시 찾지 않습니다. 원래 컬럼은 그대로 남습니다.
- **목록을 행으로 펼치기**: 목록(배열 타입, 또는 값이 JSON 배열인 글자·JSON 컬럼)이 든 컬럼을 원소마다 한 행으로 늘립니다. 예: 주문 한 행의 `상품목록`이 `["사과", "배", "감"]`이면 세 행이 되고, 컬럼 이름은 그대로이며 다른 컬럼 값(주문번호·금액 등)은 행마다 복사됩니다. 넣을 칸은 없고 고르기만 하면 됩니다. 빈 목록·빈 값·목록이 아닌 값의 행은 그 컬럼만 빈 값으로 한 행 남습니다. 목록 컬럼 둘을 같이 펼치면 행마다 원소 수의 곱(2개 × 3개 = 6행)이 됩니다. 행이 늘어나므로 합계·건수를 낼 때 같은 주문이 여러 번 세어지지 않게 주의하세요. 행으로 펼치기를 못 하는 연결(파일 연결 등)에서는 오류로 알립니다. 쿼리의 `펼치기` 줄과 같은 일입니다.
- 숫자로 바꿀 수 없는 값은 빈 값이 됩니다. 실수를 정수로 바꾸면 소수점은 0 쪽으로 버립니다(2.9 → 2, -2.9 → -2). 글자 컬럼은 정수 모양(`'12'`)만 정수로 바뀌고, `'2.9'`·`'1e3'` 같은 소수·지수 모양은 빈 값이 됩니다(먼저 실수로 바꾼 뒤 정수로 바꾸면 2가 됩니다).
- 날짜로 바꿀 때 형식에 맞지 않는 값과 없는 날짜(2026-02-30, 평년의 2월 29일)는 빈 값이 됩니다. 형식에 시각(`%H` 등)이 있으면 날짜시간이 됩니다.
- 실수 컬럼의 무한대 값(과 NaN)은 빈 값으로 봅니다. 그래서 빈 값 처리·범위 밖 값 처리·크기 맞추기와 컬럼 요약에서 빈 값으로 셉니다. 글자 `"1e400"`처럼 실수에 들어가지 않는 값을 실수로 바꾸면 무한대 대신 빈 값이 됩니다.
- 반올림은 0.5를 0에서 먼 쪽으로 올리고(2.5 → 3), 자릿수 0이면 3.0처럼 실수로 남습니다.
- 범위 밖 값의 경계(IQR·표준편차)는 그 단계를 시작할 때의 표로 구하고, 평균·중앙값으로 채울 값과 크기 맞추기는 앞 컬럼들이 행을 뺀 뒤의 표로 구합니다.

## ④ 새 컬럼

![새 컬럼: 계산 컬럼 칸과 함수 찾기 패널](../photo/prep-new-column.png)

④는 위쪽 **계산 컬럼**과 아래쪽 **쓸 수 있는 기능**(PCA·K-Means·좌표) 두 부분입니다.

**계산 컬럼**

1. **새 컬럼 이름**과 식(예: `금액 * 수량`, `median(금액)`, `lag(금액, 1)`)을 씁니다. 식에는 이름을 바꾸기 전의 컬럼 이름을 씁니다.
2. 필요하면 **정렬 기준**과 **묶을 컬럼**을 고릅니다(둘 다 선택). 순위·이전 값·누적처럼 순서가 필요한 함수는 정렬 기준을 쓰고, 묶을 컬럼을 고르면 합계·중앙값 같은 집계와 순위를 그 컬럼의 값별로 따로 계산합니다(비우면 표 전체).
3. **[추가]**를 누릅니다. 추가한 계산 컬럼은 `단가 = 금액 / 수량`처럼 칩으로 보이고(정렬·묶음을 골랐으면 괄호 안에 함께) ×로 뺍니다.

정렬 기준·묶을 컬럼 고르는 법:

- **찾는 칸**(`정렬 기준(선택): 컬럼을 찾고 Enter`, `묶을 컬럼(선택): 컬럼을 찾고 Enter`)에 컬럼 이름의 일부를 적고 **Enter**를 누르면, 이름에 그 글자가 든 컬럼이 아래에 **단추**로 나옵니다(똑같은 이름이 맨 앞, 대소문자 구분 없음). 빈 칸에서 Enter를 누르거나 옆의 **[목록 ▾]**을 누르면 모든 컬럼이 나옵니다.
- 단추를 누르면 고르고, 한 번 더 누르면 뺍니다(여러 개 고를 수 있음). 고른 컬럼은 아래에 칩으로 쌓입니다.
- 정렬 기준 칩에는 **[▲ 오름]**·**[▼ 내림]** 단추가 있어 누를 때마다 오름차순·내림차순이 바뀌고, **×**로 뺍니다.
- 목록은 **[접기 ▴]**나 Esc로 접습니다.

그 밖에:

- **[함수 찾기]**를 누르면 함수 사전이 열립니다. 분류로 거르고 예시를 누르면 식에 들어갑니다([함수 사전](sql_functions.md)).
- 식 쓰는 법 설명은 **"사칙연산과 함수를 쓸 수 있어요. 예: 금액 * 수량"** 줄에 접혀 있고, 누르면 펼쳐집니다. 나누는 값이 0이면, 로그가 0 이하면, 제곱근이 음수면 빈 값이 됩니다(펼친 안내 글에 적혀 있음).
- **행 단위 함수**: 한 행의 여러 컬럼을 한 값으로 줄입니다. `row_sum`·`row_mean`·`row_std`·`row_min`·`row_max`·`row_count`(빈 값 아닌 수)·`row_positive`(0보다 큰 수)(a, b, …)는 빈 값을 건너뛰고, `row_argmax`·`row_argmin`은 가장 큰·작은 컬럼의 이름을, `row_dist`·`row_cosine`(a1, a2, b1, b2)은 앞 절반과 뒤 절반(뒤 절반은 수도 됨)의 유클리드 거리·코사인 유사도를 줍니다. 함수 하나에 넣을 값은 50개까지입니다.
- **새 컬럼 상자**(① 데이터의 컬럼 목록 옆 **+**)는 쿼리 화면과 같은 상자로, 왼쪽에서 방식 16개(계산·조합, 여러 컬럼 압축·거리, 조건·분류, 표시(0/1) 플래그, 구간 나누기(자동), 날짜·시각, 글자, 순서·창, 그룹별 집계 붙이기, 통계 변환, 인코딩·치환, 구조, 행동 분석 틀, 지리, 다른 테이블, 식 직접) 중 하나를 고르고 오른쪽 칸을 채우면 아래에 5행 미리보기가 나옵니다. 이름을 쓰고 **[추가]**합니다. 그중 **여러 컬럼 압축·거리**는 위 행 단위 함수와 가중 합·구성비(각 컬럼 ÷ 합)·지배 비율(최대 ÷ 합과 그 컬럼)을 만듭니다. **표시(0/1) 플래그**는 0이면·임계치·상위 %·평균/중앙값보다 크면·범위 안·값 목록·이상치·여러 조건 조합(AND·OR·XOR·NOT)·직전 값과 달라지면·그룹의 첫·마지막 행이면 1입니다. **구간 나누기(자동)**는 위 "자동으로 구간 나누기"의 방식에 경계값 직접이 더해집니다.

![가운데 [컬럼 요약] 탭(표본 요약·명세서 설명)과 오른쪽 ④ 새 컬럼: 계산 컬럼 단가 = 금액 / 수량, PCA와 좌표 칸](../photo/prep-spec.png)

**쓸 수 있는 기능 (PCA·K-Means·좌표)**

계산 컬럼 아래 **쓸 수 있는 기능** 목록에 **PCA(차원 줄이기)**·**K-Means(군집 번호)**·**좌표** 세 줄이 한 줄 설명과 함께 있습니다. 처음에는 설정 칸이 접혀 있고, **줄을 눌렀을 때만 그 기능의 설정 칸이 펼쳐집니다**. 다시 누르면 접힙니다. 컬럼을 골라 쓰고 있는 기능은 줄에 **쓰는 중**이 보이고 늘 펼쳐 둡니다.

- **PCA(차원 줄이기)**: 숫자 컬럼을 체크하고 **성분 수**(처음 2)를 정하면 `pca_1`, `pca_2` … 컬럼으로 줄입니다. **[선택 해제]**로 뺍니다. 펼치면 맨 위에 **계산 기준**이 먼저 보입니다.
  - 표준화: 컬럼마다 평균을 빼고 표준편차로 나눕니다(단위가 달라도 같은 무게).
  - 빈 값: 고른 컬럼 중 하나라도 비어 있는(NaN 포함) 행은 계산에서 빼고, 그 행의 성분도 빈 값입니다.
  - 성분 구하기: 표준화한 컬럼의 상관 행렬을 고유값 분해해 설명력이 큰 순서로 성분을 뽑습니다. 부호는 계수의 절댓값이 가장 큰 컬럼이 양수가 되게 정합니다.
  - 컬럼은 2개부터 화면에 적힌 상한까지, 성분 수는 1부터 고른 컬럼 수까지입니다. 값이 모두 같은 컬럼은 넣을 수 없습니다.
- **K-Means(군집 번호)**: 숫자 컬럼을 2개 이상 체크하고 **군집 수**(기본 3, 2~10)와 **새 컬럼 이름**(기본 `cluster`)을 정하면, 비슷한 행끼리 나누고 군집 번호(0부터)를 새 컬럼으로 붙입니다. 컬럼은 10개까지 넣고, 표를 군집마다 반복해 집계하므로 최대 수십 번 읽습니다. **[선택 해제]**로 뺍니다. 펼치면 **계산 기준**이 먼저 보입니다.
  - 표준화: 컬럼마다 평균을 빼고 표준편차로 나눕니다.
  - 거리: 표준화한 값의 유클리드 거리가 가장 가까운 중심의 군집에 넣습니다.
  - 처음 중심: 표의 앞쪽 행(행 수는 화면에 적혀 있음)에서 k-means++로 고릅니다. 난수 씨앗이 고정이라 같은 표면 결과가 같습니다.
  - 반복: 배정하고 중심을 군집 평균으로 옮기기를 되풀이하다가, 중심이 거의 움직이지 않거나 정해진 횟수를 채우면 멈춥니다(기준 값과 횟수는 화면에 적혀 있음). 행이 없는 군집은 이전 중심을 그대로 씁니다.
  - 빈 값: 고른 컬럼 중 하나라도 비어 있는(NaN 포함) 행은 계산에서 빼고, 군집 번호도 빈 값입니다.
- **좌표**: TM 좌표를 경도·위도로 바꾸거나, 가장 가까운 지점·속한 영역을 새 컬럼으로 붙입니다. 종류(TM 좌표를 경도·위도로·가장 가까운 지점 찾기·속한 영역 붙이기)를 고르고 칸을 채워 **[좌표 추가]**를 누릅니다(이 PC에서 계산, [좌표](geo.md)).

## ⑤ 중복 제거 · ⑥ 정렬

![⑤ 중복 제거(고객ID, 중복 찾기 결과)와 ⑥ 정렬(고객ID 오름차순·금액 내림차순)](../photo/prep-dedup-sort.png)

⑤ 중복 제거는 기준을 고르고 → 찾아 보고 → 확정하는 차례입니다.

1. **컬럼 추가** 목록에서 기준 컬럼을 고릅니다(칩으로 쌓이고 ×로 뺌). 고른 컬럼의 값이 모두 같은 행은 하나만 남깁니다. **[모든 컬럼]**은 모든 컬럼을 기준으로 넣어 완전히 같은 행만 지웁니다. 하나도 안 고르면 모든 컬럼이 기준입니다.
2. 필요하면 비교 방법을 정합니다.
   - **글자 다듬어 비교**: 공백·문장부호·기호를 빼고 대소문자를 무시해 비교합니다.
   - 글자 컬럼 칩의 **[포함]**: 짧은 값이 긴 값 안에 통째로 있으면 같은 값으로 봅니다(누르면 **포함 ✓**). 포함을 쓰면 **상한** 칸이 나오고, 비교할 서로 다른 값 조합이 이보다 많으면 계산하지 않습니다.
   - 남길 행: 기본은 **아무 행이나 하나 남기기**입니다. **남길 값 직접 고르기**를 고르면 정렬 기준의 첫·마지막 행, 최소·최대·최빈값, 이어 붙이기 등으로 남길 값을 정합니다.
3. **[중복 찾기]**를 누르면 `중복 묶음 N개, 빠질 행 N개`와 겹친 행의 예시 표가 나옵니다. 이 연결이 그 비교를 못 하면 이 PC 작업 사본에서 계산했다고 알립니다.
4. 결과가 맞으면 **[이 기준으로 지우기]**를 누릅니다. 눌러야 중복 제거가 전처리에 들어가고, 아래에 `지울 기준: …`이 보입니다. **[지우지 않기]**로 취소합니다. 기준 칸을 바꾸면 [중복 찾기]를 다시 눌러야 [이 기준으로 지우기]가 나옵니다.

⑥ 정렬은 결과 컬럼과 오름차순·내림차순을 골라 **[추가]**합니다. 여러 개를 넣으면 넣은 차례대로 정렬하고, 칩의 ×로 뺍니다.

## 컬럼 요약

가운데 표 위에는 **[데이터]**·**[컬럼 요약]** 탭이 있습니다. 위 사진의 **[컬럼 요약]** 탭은 컬럼마다 쉬운 요약(타입, 빈칸 수, 범위, 값 종류)과 명세서 파일의 설명, 추천을 보여 줍니다. 자주 보는 것만 펼쳐 두고 나머지는 눌러서 펴는 접이식입니다.

탭은 위에서 아래로 이렇게 놓여 있습니다.

| 자리 | 보이는 것 |
|---|---|
| 맨 위 한 줄 | `표본 5,000행으로 구한 통계예요(구한 때).`처럼 **짧은 표본 설명**과 단추 **[다시 구하기]**·**[전체로 구하기]**·**[진단 기준]**, 오른쪽에 **[뺄 만한 컬럼 찾기]**·**[추천 모두 적용]** |
| **표본을 어떻게 읽었는지** (접이식) | 계획한 행 수·파일럿 행 수·읽은 방법·기준 컬럼, 이 표본의 오차(비율 ±%p, 신뢰수준), 층화 추정 값. 짧은 설명에 마우스를 올려도 읽은 방법과 건너뛴 방법이 나옵니다 |
| 주의 줄 | 표본에 대해 꼭 알아야 할 주의만 늘 보입니다 |
| **점검 메모 N개** (접이식) | 컬럼마다의 점검 줄(`컬럼 · 내용`)과 표 전체 줄. 펼쳐야 보입니다 |
| **백분위수** (접이식) | 숫자 컬럼의 값이 어디에 몰려 있는지 표 |
| **조합 키** (접이식) | 묶으면 값이 겹치지 않는 컬럼 조합 찾기 |
| **키 중복** (접이식) | 같은 키가 여러 번 나오는지 |
| **빈 시간 구간** (접이식) | 값이 하나도 없는 날·시간 |
| **참조 무결성** (접이식) | 다른 테이블에 없는 키 |
| 컬럼 표 | 컬럼 · 빈 값 비율 · 고유값 수 · 표본 요약 · 명세서 설명 · 추천. 줄을 누르면 ③ 컬럼 정리에서 그 컬럼이 열립니다 |
| **요약을 파일로 저장** (접이식) | 연결의 모든 테이블의 요약을 파일로 |
| 명세서 파일 | 경로 칸과 **[불러오기]** |

- 컬럼 표의 **표본 요약** 칸은 **세 줄**(타입·빈칸·범위)만 보이고, 나머지는 그 아래 **[자세히 N줄]**을 눌러 폅니다. 접힌 줄에 주의가 있으면 `자세히 5줄 · 주의 1`처럼 개수를 알려 줍니다. [자세히]를 눌러도 컬럼이 골라지지는 않습니다.
- 백분위수부터 참조 무결성까지의 다섯 접이식은 진단 결과가 있을 때 나옵니다.
- **[추천 모두 적용]**: 추천한 정리 방법을 한꺼번에 넣습니다(추천이 있을 때만 보임). **[뺄 만한 컬럼 찾기]**: 값이 하나뿐이거나 다른 숫자 컬럼과 상관이 아주 높은 컬럼을 표본으로 찾습니다(DB에는 묻지 않음).
- **점검 메모**에는 표본 기준의 품질 점검 줄이 들어 있습니다: **키 후보**(빈 값이 없고 값이 모두 다른 컬럼), **IQR 밖 값**(사분위 범위의 1.5배 밖인 값이 몇 개인지, 숫자 컬럼), **빈 날**(처음~마지막 날 사이 값이 없는 날이 며칠인지, 날짜 컬럼)과 아래 자동 진단의 줄들. 없으면 그 줄은 나오지 않습니다.
- 컬럼 이름에 금액 단서(amount·금액·매출 …)가 있는 숫자 컬럼에 빈 값이 있으면 추천에 **빈 값을 0으로 채우기**가 먼저 나옵니다.
- **자동 진단(표본)**: 통계가 끝나면 표본으로 컬럼마다 진단 줄이 더 붙습니다(실패해도 통계는 그대로 보임). 진단 줄은 **점검 메모**와 컬럼 표의 표본 요약([자세히] 안)에서 봅니다. 숫자: 0·음수·양수 비율, 평균·표준편차·왜도·첨도, Z-Score·MAD 밖 값 수, 벤포드 이탈(잘 맞음·맞는 편·조금 다름·다름), 0이 많음, 치우침, 봉우리 여럿, 더미 값으로 보이는 숫자, 숫자 쏠림(10의 배수 등). 글자: 평균 글자 수·바이트, 엔트로피·지니, 공백만 있는 값·탭·줄바꿈이 든 값·보이지 않는 문자·깨진 글자, 날짜 형식이 섞인 정도, JSON으로 읽히는 값, 해시·UUID 모양. 날짜: 기본값으로 채운 듯한 날짜와 미래 시점. 이진·순서형 같은 성격은 컬럼 이름 옆 태그(**이진**·**순서형**·**ID·해시**·**JSON** 등)로 보이고, 표 전체 줄에는 모든 컬럼이 같은 행과 시작보다 끝이 앞선 행(시간 역전)이 나옵니다. 숫자 컬럼의 백분위수 표는 **백분위수** 접이식에 있습니다.
- **[진단 기준]**: 이상치 배수(IQR 1.5·Z-Score 3·수정 Z-Score 3.5)·더미 숫자·기본값 날짜·더할 빈 값 표시·순서 척도·백분위수 등 진단 기준을 바꿉니다. 칸을 비우면 기본값이고 **[저장]**하면 같은 표본으로 다시 구하며, **[기본값으로]**로 되돌립니다.
- **진단 도구**(접이식을 펼치면 단추가 나옴):
  - **조합 키** → **[조합 키 찾기]**: 표본에서 2~3개를 묶으면 값이 겹치지 않는 컬럼 조합을 찾습니다(이 PC에서만 계산). 후보마다 **[전체로 확인]**으로 테이블 전체에서 확인합니다.
  - **키 중복** → 컬럼을 체크하고 **[키 중복 보기]**: 고른 컬럼 기준으로 테이블 전체의 중복 묶음과 겹친 횟수 분포를 봅니다. **[전체 중복 행 세기]**는 모든 컬럼 값이 같은 행을 셉니다.
  - **빈 시간 구간** → 날짜 컬럼과 단위(일·시간)를 고르고 **[빈 구간 찾기]**: 처음~마지막 사이에서 값이 하나도 없는 구간을 찾습니다.
  - **참조 무결성** → 차원 테이블과 키 쌍(**[+ 키]**로 더함)을 고르고 **[참조 무결성 확인]**: 이 테이블의 키가 차원 테이블에 없는 행·키의 비율을 구합니다.
  - 조합 키 찾기는 표본, 나머지는 테이블 전체를 읽고 결과 아래에 "테이블을 N번 읽었어요"가 보입니다. BigQuery처럼 읽는 양을 먼저 확인하는 연결에서는 확인 창에 "표를 N번 읽어요"와 단계별 읽는 양·합계가 나옵니다.
- **ID·해시 컬럼 빼기**: 해시·UUID 모양의 컬럼은 쿼리의 집계·차트 그룹 목록과 분석 탭의 묶기·집계 목록에서 빠지고, 목록 아래에 "ID·해시로 보이는 컬럼 …을(를) 목록에서 뺐어요"와 **[다시 넣기]**가 나옵니다. 왼쪽 메뉴 [설정] 창 [계산] 분류의 **ID·해시 컬럼을 묶기·집계 목록에서 빼기**(기본 켜짐, [설정](settings.md#기억되는-것))를 끄면 빼지 않습니다.
- **[다시 구하기]**: 표본을 새로 읽어 요약·추천을 다시 구합니다.
- **[전체로 구하기]**: 표본이 아니라 테이블 전체 값으로 빈 값·고유값·최솟값·최댓값을 다시 구합니다. 표본과 크게 다르면(빈 값 비율 5%p 이상, 고유값 수 20% 이상, 최솟값·최댓값이 다름) 그 컬럼에 **표본과 달라요**가 표시됩니다. 큰 테이블은 오래 걸리고, 쓴 만큼 요금을 받는 DB에서는 비용이 듭니다. 컬럼 8개씩 나눠 집계해서, 컬럼이 아주 많은 테이블도 DB 메모리를 한꺼번에 쓰지 않습니다.
- **요약을 파일로 저장**(접이식, 컬럼 표 아래) → **[요약 파일로 저장]**: 연결의 모든 테이블의 컬럼 요약(타입·빈 값 비율·빈 값 수·고유값 수·최솟값·최댓값·예시 값)을 파일 하나로 저장합니다. 테이블이 많으면 오래 걸립니다. 형식은 **Excel**(첫 시트에 테이블 목록, 테이블마다 시트 하나) 또는 **CSV**(테이블 이름 컬럼이 붙은 표 하나)이고, **전체 기준**을 체크하면 표본 대신 전체로 구합니다. 행 데이터는 예시 값 3개까지만 들어갑니다.
- **명세서 파일**: 테이블·컬럼 설명을 적은 YAML·JSON 파일 경로를 넣고 **[불러오기]**를 누릅니다. 설명은 [질문으로 SQL 만들기](sql.md)도 씁니다. 비우고 [불러오기]를 누르면 쓰지 않습니다.

```yaml
tables:
  orders:
    description: 2026년 주문 내역
    partition: {column: order_date, recent_days: 3}   # 날짜로 나뉜 테이블이면 최근 3일만 표본으로
    columns:
      금액: {description: "결제 금액(원, 할인 뒤)"}
```

## 미리보기와 저장

![⑦ 저장: 파일·새 테이블, 숫자 컬럼 줄이기, 설정 저장](../photo/prep-save.png)

- 패널 아래에 **[미리보기]**와 **[실행]**이 있습니다. [미리보기]는 앞 20행만 보고 저장하지 않으며, [실행]은 테이블 전체를 ⑦ 저장에서 고른 곳에 만듭니다.
- **[미리보기]**: 정리한 결과의 앞 20행과 `행 수: 전처리 전 3,200행, 후 2,950행`을 보여 줍니다. 미리 본 뒤 조건을 바꾸면 "설정이 바뀌었어요. [미리보기]를 다시 눌러 주세요"라고 알려 줍니다.
- ⑦ **저장**의 **저장할 곳**: **파일**(Parquet·CSV) 또는 **같은 DB의 새 테이블**. 새 테이블은 **새 테이블 이름**을 적고 [실행]을 누르면 단추가 "한 번 더 누르면 ‘이름’ 테이블을 만들어요"로 바뀌고, 한 번 더 눌러야 만듭니다. 같은 이름의 테이블이 있으면 만들지 않습니다.
- **숫자 컬럼을 더 작은 타입으로 줄이기**(downcast): 값이 바뀌지 않을 때만 줄입니다(예: int64 → int16).
- **설정 저장**: 지금 고른 전처리 전체를 이름(**설정 이름**)을 붙여 저장해 두고, 다음에 골라 그대로 불러옵니다(불러오기만 하고 실행하지는 않음).
- 어떤 것이 기억되는지는 [설정](settings.md)에 있습니다.
