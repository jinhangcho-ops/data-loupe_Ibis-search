**한 줄 요약**: 수익화·마케팅 지표의 식과 필요한 컬럼입니다. 쓰는 법은 [지표 사전](metrics_catalog.md) 첫 문서에 있습니다.

## 수익화·LTV (14개)

금액이 0보다 큰 행을 결제로 본다. 수수료·부가세·환불은 직접 적는다.

| 지표 | 식 | 필요한 컬럼 |
|---|---|---|
| 총매출 (Gross Revenue) | 금액의 합 | 금액 |
| 순매출 (Net Revenue) | (총매출 − 환불) ÷ (1 + 부가세) × (1 − 수수료) | 금액 |
| 결제 사용자 수 (PU) | 금액 > 0인 고유 사용자 수 | 사용자·금액 |
| 신규 결제자 (NPA) | 기간 안 첫 결제가 그 기간인 고유 사용자 수 | 사용자·금액·시각 |
| 결제 비율 (PUR (DPUR/MPUR)) | 결제자 ÷ 활동 사용자 | 사용자·금액·시각 |
| 사용자당 매출 (ARPU) | 매출 ÷ 활동 사용자 | 사용자·금액 |
| 결제자당 매출 (ARPPU) | 매출 ÷ PU | 사용자·금액 |
| 일 활성 사용자당 매출 (ARPDAU) | 매출 합 ÷ 일별 DAU의 합 | 사용자·시각·금액 |
| 고객 생애 가치 (LTV (LTV7/30/90)) | N일 안 코호트 매출 ÷ 코호트 크기 (또는 ARPU ÷ Churn) | 사용자·시각·금액 |
| 재구매율 (Repeat Purchase Rate) | N번 이상 산 사용자 ÷ 구매 사용자 | 사용자·금액 |
| 고래·돌고래·잔챙이 비중 (Whale/Dolphin/Minnow Share) | 등급별 매출 ÷ 전체 매출 | 사용자·금액 |
| 월 반복 매출 (MRR) | 월별 금액의 합 | 시각·금액 |
| 연 반복 매출 (ARR) | MRR × 12 | 시각·금액 |
| 순매출 유지율 (NRR) | 지난달 매출 있던 고객의 이번 달 매출 ÷ 지난달 매출 | 사용자·시각·금액 |

## 마케팅·UA (16개)

표의 *는 광고비 테이블의 컬럼이다. 광고비가 다른 테이블에 있으면 ‘기간 단위로 맞춰’ 또는 ‘공통 키로 맞춰’를 골라야 구한다. 광고 날짜 컬럼을 고르면 사용자 쪽 날짜 범위의 광고비만 센다(안 고르면 기간이 안 걸린다고 알려 준다). 공통 키로 맞추면 사용자 한 명은 첫 활동의 키 하나에만 센다.

| 지표 | 식 | 필요한 컬럼 |
|---|---|---|
| 노출 수 (Impressions) | 노출 수의 합(컬럼이 없으면 행 수) | 없음 |
| 도달 사용자 (Reach) | 고유 사용자 수 | 사용자 |
| 노출 빈도 (Frequency) | 노출 수 ÷ 도달 | 사용자 |
| 클릭률 (CTR) | 클릭 ÷ 노출 | 클릭 수·노출 수 |
| 노출 천 번당 설치 (IPM) | 설치 ÷ 노출 × 1000 | 설치 수·노출 수 |
| 노출 천 번당 비용 (CPM) | 광고비 ÷ 노출 × 1000 | 광고비·노출 수 |
| 클릭당 비용 (CPC) | 광고비 ÷ 클릭 | 광고비·클릭 수 |
| 설치당 비용 (CPI) | 광고비 ÷ 설치 | 광고비·설치 수 |
| 행동당 비용 (CPA) | 광고비 ÷ 전환 | 광고비·전환 수 |
| 고객 획득 비용(전체) (CAC (Blended)) | 광고비 ÷ 신규 사용자(오가닉 포함) | 사용자·시각·광고비* |
| 고객 획득 비용(유료) (CAC (Paid)) | 광고비 ÷ 유료 유입 신규 사용자 | 사용자·시각·유입 경로·광고비* |
| 광고 수익률 (ROAS (D1/D7/D30)) | 첫 활동 후 N일 누적 매출 ÷ 광고비 | 사용자·시각·금액·광고비* |
| LTV 대 CAC (LTV:CAC) | LTV ÷ CAC | 사용자·시각·금액·광고비* |
| 회수 기간 (Payback Period) | 누적 ARPU ≥ CAC가 되는 첫 Day-N | 사용자·시각·금액·광고비* |
| 바이럴 계수 (K-Factor) | 초대 수/사용자 × 초대 전환율 | 사용자·보낸 초대 수·초대로 가입한 수 |
| 오가닉 상승분 (Organic Uplift) | 오가닉 신규 ÷ 유료 신규 | 사용자·시각·유입 경로 |
