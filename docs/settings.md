## 진행 상황과 취소

위쪽 줄 오른쪽에 `PC 메모리 51%`, `PC CPU 18%`, `프로그램 594 MB`, 그리고 `● 끝 예상 0.1초 · 걸린 시간 1.2초`처럼 지금 작업이 보입니다.

- 작업이 도는 동안 [취소]를 누르면 멈춥니다. 30분이 넘는 작업은 저절로 멈춥니다.
- **예상** 시간은 "행 수 × 지난번 비슷한 크기에서 한 행에 걸린 시간"으로 어림합니다. 처음에는 `—`이고, 몇 번 쓰면 생깁니다.
- 검색이 너무 오래 걸리면 [취소] 후 기간·조건을 좁히세요. PC 메모리가 90% 가까이 오르면 연결 카드의 **작업 메모리 상한**(DuckDB 파일만)을 정하세요. 계산 중에 PC가 너무 무거우면 연결 카드의 **계산 코어 수**를 줄이세요(DuckDB 파일과 PC에 받아 둔 결과에 적용, 대신 큰 계산은 느려짐).
- 회사 DB에 연결하면 계산은 DB 서버가 해서 PC 숫자는 거의 움직이지 않습니다.

## 안전하게 쓰기 (자세히)

| 걱정 | 프로그램이 하는 일 |
|---|---|
| 실수로 데이터를 망가뜨리면? | 검색·SQL은 읽기만 합니다(데이터를 바꾸는 문장과 SQL 안의 파일·환경 값 읽기는 막음). DB에 쓰는 일은 분석의 "새 테이블 만들기"와 수집의 적재뿐입니다. 회사 DB에는 읽기 전용 계정을 권합니다 |
| 비밀번호가 새면? | DB·Kafka 비밀번호는 메모리에만 두고 파일에 저장하지 않으며, 오류 문구에서도 가립니다. 토큰·키는 서비스마다 고른 방식으로만 둡니다 |
| 요금 폭탄 | 실행 전에 [처리 용량](query.md#탐색-오른쪽-패널-18번)과 [SQL 보기]로 확인하세요. 결과는 한 번만 조회하고 쪽 넘기기는 PC나 BigQuery의 결과 임시 테이블에서 읽어 다시 과금되지 않습니다. [전체 행 수 세기]를 끄면 조회가 줄어듭니다 |
| 엑셀 파일의 악성 수식 | CSV·Excel로 저장할 때 `=`, `+`, `-`, `@`로 시작하는 값과 컬럼 이름 앞에 `'`를 붙여 수식으로 실행되지 않게 합니다. 수집 결과 CSV도 같습니다(그 CSV를 적재하면 `'`가 붙은 채로 들어가니 그대로 넣을 값이면 Parquet으로 받으세요) |
| 몰래 밖으로 보내지 않나? | 보낼 곳·Slack 봇·GA4·AI를 설정하고 쓸 때만 그 서비스와 통신합니다. AI에는 데이터 값을 보내지 않습니다. 위쪽 [설정]에서 기능을 바꾸면 GitHub Releases에서 설치 프로그램을 받습니다([설치](../README.md#프로그램-받기)). 그 밖에는 인터넷으로 아무것도 보내지 않습니다 |
| 수집이 키를 엉뚱한 곳에 보내면? | 응답이 다른 호스트로 넘겨주면(조각으로 받을 때도) 인증 헤더와 비밀 값이 든 헤더를 빼고 보냅니다. https에서 http로 넘겨주면 따라가지 않고, 다음 쪽 주소가 처음 요청과 호스트나 방식(https→http)이 다르면 멈춥니다 |
| DB 서버가 PC 파일을 읽어 가면? | MySQL·SingleStore 연결은 서버가 PC의 파일을 가져가는 `LOAD DATA LOCAL INFILE`을 끕니다 |
| 이상하게 큰 설정 파일 | 목표 파일·데이터 명세서는 5MB까지 읽고, YAML의 항목·값(별칭은 펼친 수)이 10만 개가 넘는 목표 파일, 한 줄이 4,096자를 넘는 md·txt 목표 파일, 테이블·컬럼이 모두 20만 개를 넘는 명세서는 이유를 알리고 읽지 않습니다 |
| AI가 이상한 SQL을 만들면? | 자동으로 실행하지 않고 같은 검사를 거친 뒤 사람이 확인하고 [실행]합니다 |
| 임시 파일 | `%TEMP%\DataLoupe\` 아래에 만들고 다 쓰면 지웁니다. 회사 DB에서 받아 둔 검색 결과도 여기에 두고 연결을 바꾸거나 끊으면 지웁니다. 이 프로그램이 만든 표시가 있는 폴더만 지웁니다 |
| 다른 프로그램의 접속 | 실행할 때마다 새 열쇠를 만들어 이 프로그램 창의 요청만 받습니다 |

## 자세히 정하는 값

[연결] 카드의 '자세히'에 있습니다.

- **용량을 알 수 없을 때**: 처리 용량을 미리 셀 수 없으면 그대로 실행(기본)할지, 실행하지 않을지. 검색·SQL 실행, 결과 저장, 전처리 실행 전에 용량이 작업 메모리 상한(제한 없음이면 그때 PC의 사용 가능 메모리)을 넘으면 [확인]을 눌러야 실행합니다. 쪽 넘기기는 묻지 않습니다. 회사 DB는 **PC로 받는 양**만 견주고, 요금이 나올 수 있어 행을 세거나 표본을 읽지 않고 DB가 가진 정보(파티션·실행 계획·통계·명세서의 컬럼별 `"bytes"`·타입)로 어림합니다. 받는 도중 상한을 넘으면 멈추고 지웁니다. 회사 DB의 파일 직접 저장, DB 안의 집계 결과, 이미 받아 둔 결과는 묻지 않습니다.
- **표본 최소 비율(%)**: 컬럼 추론의 블록 샘플링이 기대한 행의 이 비율도 못 가져오면 다음 방법으로 넘어갑니다. 5~90%, 비우면 20%.

표본 5,000행과 20%는 근거 없이 정한 기본값일 뿐이며 바꿀 수 있습니다(표본 행 수는 전처리 화면에서, 비율은 위 칸에서).

## 기억되는 것

설정은 `%APPDATA%\DataLoupe\` 폴더(파일 탐색기 주소창에 그대로 넣으면 열림)에 저장됩니다. 저장한 검색·SQL·전처리 구성·대시보드(암호화)·수집 구성·예약, 보낼 곳, 업로드 기록, 화면 설정, 임시 저장([drafts.md](drafts.md)) 등이 들어 있고 **비밀번호는 없습니다.** 파일을 지우면 그 내용만 처음 상태로 돌아가고, 덮어쓰기 전에는 `.bak`으로 하나 남겨 둡니다.

**PC를 바꿀 때**: 이 폴더를 통째로 복사하면 그대로 옮겨집니다. 단, "암호화해 저장"한 토큰은 새 PC에서 다시 입력하세요. 대시보드는 새 PC에서 풀 수 없습니다.

## DB별 드라이버

회사 DB 주소 모양입니다. 주소와 읽기 전용 계정은 보통 DB 담당자에게 받습니다. 필요한 드라이버가 없으면 프로그램이 설치 방법을 알려 줍니다.

| DB | 주소 예 |
|---|---|
| PostgreSQL([Supabase](supabase.md)) / MySQL | `postgres://host:5432/db` / `mysql://host:3306/db` |
| MSSQL | `mssql://host:1433/db` ([ODBC Driver 17/18](https://learn.microsoft.com/sql/connect/odbc/download-odbc-driver-for-sql-server) 필요. 아이디·비밀번호를 비우면 Windows 로그인) |
| Oracle / ClickHouse / Trino | `oracle://host:1521/db` / `clickhouse://host:8123/db` / `trino://host:8080/catalog/schema` |
| Snowflake | `snowflake://계정/데이터베이스/스키마?warehouse=WH` |
| BigQuery | `bigquery://프로젝트/데이터셋` (처음 접속 때 Google 로그인) |
| Databricks / Athena | `databricks://?server_hostname=…&http_path=…` / `athena://?s3_staging_dir=s3://…&region_name=…` |
| DuckDB / SQLite 파일 | `duckdb://data.duckdb` / `sqlite://data.db` |

그 밖에 Druid, Exasol, Materialize, RisingWave, SingleStore도 됩니다. DW(Redshift는 `postgres://`, Synapse는 `mssql://`로 접속)와 DL(Trino, Spark·Flink는 Java가 필요하고 소스로 실행할 때만, DuckDB 확장 httpfs·delta·iceberg)도 같은 방식입니다.

**드라이버 확인**: 연결 카드의 [DB 주소] 탭에서 [드라이버 확인]을 누르면 DB·DW·DL별로 설치됨·없음·프로그램 필요와 설명, 설치 명령([복사])이 나옵니다. 연결이 드라이버 때문에 실패해도 같은 설명과 명령이 그 자리에 뜹니다. 프로그램은 아무것도 자동으로 받거나 설치하지 않으니 명령을 직접 실행하세요. 소스 실행은 `pip install "ibis-framework[x]==버전"`, exe는 `py -3.14 -m pip install --target "%APPDATA%\DataLoupe\drivers" "ibis-framework[x]==버전"`을 실행한 뒤 프로그램을 다시 켭니다(Python 3.14 필요, [python.org](https://www.python.org/downloads/)).

**예**: 회사 Postgres 서버 `db.company.local`의 `sales` DB → 주소 `postgres://db.company.local:5432/sales`, 아이디·비밀번호는 칸에 따로(주소에 비밀번호를 쓰지 마세요).
