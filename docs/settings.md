**한 줄 요약**: 화면을 내 마음대로 바꾸는 법, 작업이 얼마나 걸리는지 보는 법, 프로그램이 내 PC에 무엇을 기억하는지, 회사 DB에 연결하는 주소 모양을 모아 둔 곳입니다.

## 진행 상황과 취소

위쪽 줄 오른쪽에 PC 상태와 지금 하는 작업이 보입니다.

| 보이는 것 | 뜻 |
|---|---|
| `PC 메모리 51%` | PC 전체 메모리를 얼마나 쓰고 있는지 |
| `PC CPU 18%` | PC 전체 CPU(계산 장치)를 얼마나 쓰고 있는지 |
| `프로그램 594 MB` | 그중 이 프로그램(화면 포함)이 쓰는 메모리 |
| `● 끝 예상 0.1초 · 걸린 시간 1.2초` | 지금(또는 마지막) 작업, 미리 어림한 시간, 실제 걸린 시간. 도는 동안에는 [취소]가 나옵니다 |

메모리·CPU는 2초마다 바뀝니다. 회사 DB 주소로 연결하면 계산은 DB 서버가 해서 이 숫자들은 거의 움직이지 않습니다.

**예**: 검색이 너무 오래 걸리면 [취소]를 누르고, 기간이나 조건을 좁혀 다시 실행하세요. PC 메모리가 90% 가까이 오르면 [작업 메모리 상한](query.md#내-폴더-파일)을 정해 보세요.

### 취소

작업이 도는 동안 시간 옆의 [취소]를 누르면 하던 검색·집계·차트·저장을 멈춥니다.

- DuckDB처럼 멈춤을 지원하는 곳은 계산 자체가 멈춥니다.
- 파일(Parquet·CSV) 연결은 기다리기만 멈추고, 하던 계산은 뒤에서 끝난 뒤 버려집니다.
- 30분이 넘는 작업은 저절로 멈춥니다.

### 걸린 시간

[검색 실행]을 누르면 0부터 다시 재고, 그 뒤의 집계·차트·저장 시간을 계속 더합니다. 예: 검색 1.0초 + 집계 2.4초 + 차트 0.1초 = 3.5초.

### 예상 시간

예상은 "이 테이블 행 수 × 지난번에 비슷한 크기를 처리할 때 한 행에 걸린 시간"으로 어림합니다.

- 작업 종류(검색·집계·차트·저장)와 테이블 크기(1천 행 미만, 1천 행대, 1만 행대…)마다 따로 기억합니다.
- 그 크기로 한 번도 해 본 적이 없으면 `—`로 나옵니다. 몇 번 쓰다 보면 생깁니다.
- 조건이나 조인에 따라 빗나갈 수 있고, 연결 직후 첫 실행은 예상보다 느릴 수 있습니다.

테이블 행 수는 테이블마다 처음 한 번 세는데, 원격 DB의 큰 테이블은 이때 시간이 걸릴 수 있습니다. [전체 행 수 세기](query.md#전체-행-수-세기)를 끄면 세지 않습니다.

## 화면 설정

### 화면 모드

위쪽 줄 오른쪽 달·해 모양 버튼으로 밝은 화면(라이트)과 어두운 화면(다크)을 바꿉니다. 처음에는 Windows 설정을 따릅니다.

![다크 모드 화면](screen-dark.png)

### 창 크기

창 크기를 바꾸면 화면 배치가 바로 따라 바뀝니다. 작은 노트북 화면에서도, 큰 모니터에서도 맞춰집니다.

- 오른쪽 패널은 창 너비의 약 28%(300~520px)입니다.
- 차트와 그래프는 창 높이에 맞춰 커지고 작아집니다.
- 대시보드 카드는 창이 넓을수록 한 줄에 더 많이 놓입니다.
- 창이 좁으면(1,280px 미만) 위쪽 줄의 PC 메모리·CPU를 숨기고, 더 좁으면(900px 미만) 패널이 결과 아래로 내려갑니다.
- 처음에는 모니터의 85% 크기로 열리고, 1,024×640보다 작게는 줄어들지 않습니다.

### 크기 조절

패널 너비, 집계 표 높이, 차트 높이를 마우스로 끌어 바꿀 수 있습니다.

1. 위쪽 줄 오른쪽 크기 조절 버튼(화살표 두 개)을 누르면 끌 수 있는 경계가 옅게 보입니다.
2. 경계를 끌어 크기를 바꿉니다. 더블클릭하면 기본 크기로 돌아갑니다.
3. 다 바꿨으면 같은 버튼을 눌러 끕니다(바꾼 크기는 기억합니다).

| 경계 | 바뀌는 것 |
|---|---|
| 결과와 오른쪽 패널 사이 | 패널 너비 |
| 집계 표 아래 가장자리 | 집계 표 높이 |
| 차트 아래 가장자리 | 차트 높이(너비는 비율에 맞춰 같이) |

![크기 조절을 켠 화면](screen-resize.png)

### 고르는 칸

목록 칸을 누르면 펼쳐집니다. 항목이 8개보다 많으면 맨 위에 [찾기] 칸이 생겨, 글자를 치면 그 글자가 든 항목만 남습니다(컬럼이 많을 때 편함). ↑↓로 옮기고 Enter로 고르며 Esc로 닫습니다.

## 안전하게 쓰기 (자세히)

| 걱정 | 프로그램이 하는 일 |
|---|---|
| 실수로 데이터를 망가뜨리면? | 검색은 읽기만 하고, 넣거나 고치거나 지우는 기능이 없습니다. 조건 칸의 글자는 SQL에 그대로 붙이지 않고 컬럼·연산자·값으로 풀어서 씁니다. SQL 탭도 읽기만 하는 SELECT 하나만 실행합니다. DuckDB 파일은 읽기 전용으로 엽니다. DB에 쓰는 일은 전처리의 "새 테이블 만들기"와 수집의 적재뿐입니다 |
| 회사 DB 계정 권한 | 프로그램이 쓰지 않을 뿐, 계정의 권한 자체는 그대로입니다. 회사 DB에는 **읽기 전용 계정**(적재는 적재 전용 계정)으로 연결하길 권합니다 |
| 비밀번호가 새면? | DB·Kafka 비밀번호는 프로그램이 켜져 있는 동안 메모리에만 두고 파일에 저장하지 않습니다. 오류 문구에 나오면 가리고, 주소 안에 쓴 비밀번호도 가립니다 |
| 요금 폭탄 | 검색·집계·차트·저장은 모두 DB에 조회를 보냅니다. 실행 전에 [처리 용량](query.md#처리-용량)과 [SQL 보기]로 확인하고, [전체 행 수 세기]를 끄면 조회가 줄어듭니다. BigQuery 처리 용량은 요금이 나오지 않는 미리 보기로 셉니다 |
| 엑셀 파일로 악성 수식이? | 엑셀은 `=`, `+`, `-`, `@`로 시작하는 칸을 수식으로 실행할 수 있습니다. 그래서 CSV·Excel로 저장할 때 그런 값 앞에 `'`를 붙입니다. 원래 값이 필요하면 Parquet으로 저장하세요 |
| 몰래 밖으로 보내지 않나? | [보낼 곳](integrations.md#다른-앱으로-보내기)을 등록하고 보내거나 알림을 켰을 때만 그곳으로 보냅니다. [수집](collect.md#수집)은 넣은 주소로만, [Slack 봇](integrations.md#slack-봇-받기)은 허용한 사람의 명령에만, [GA4](integrations.md#google-analytics-4-가져오기)는 [가져오기]를 누를 때만, AI는 [SQL 만들기]를 누를 때만(데이터 값은 빼고) 통신합니다. 그 밖에는 인터넷으로 아무것도 보내지 않습니다 |
| 토큰·키 보관 | 서비스마다 암호화 저장·이번 실행 동안만·환경변수 중 고른 방식으로만 두고, 오류 문구에서 가립니다 |
| AI가 이상한 SQL을 만들면? | AI가 만든 SQL은 자동으로 실행하지 않습니다. 편집기에 넣어 같은 검사(읽기만 하는지, 있는 테이블인지)를 거치고, 사람이 확인하고 [실행]합니다. Slack 봇은 SQL을 보여 주기만 합니다 |
| 웹페이지 수집 | 따로 띄운 수집용 창에서 읽기만 하고, 그 사이트는 프로그램 기능을 쓸 수 없습니다. API 키는 env 파일에만 두고 구성에는 이름만 저장합니다. 다른 사이트로 넘겨지면 인증 정보를 빼고 보냅니다. 받는 곳의 이용 약관과 사용 한도를 지켜 쓰세요 |
| 예약 실행 | Windows 작업 스케줄러의 `\ibis_search\` 폴더에만, 관리자 권한 없이, 로그온해 있을 때만 돌게 등록합니다. 다른 예약 작업은 건드리지 않습니다 |
| 적재 | 새 테이블 만들기, 덧붙이기, 이 프로그램이 만든 테이블 바꾸기만 합니다. 다른 데이터는 지우거나 고치지 않습니다. [업로드 기록](collect.md#업로드-기록)은 지울 명령을 보여 주기만 하고 실행하지 않습니다 |
| 임시 파일 | 저장하거나 메모리 상한을 걸 때 `%TEMP%\ibis_search\` 아래에 임시 폴더를 만들고 다 쓰면 지웁니다. 강제 종료로 남은 것은 다음 실행 때 지우는데, 이 프로그램이 만든 표시가 있는 폴더만 지우고 다른 파일은 건드리지 않습니다 |
| 다른 프로그램이 몰래 접속하면? | 실행할 때마다 새 열쇠를 만들어 프로그램 창의 요청만 받습니다. 같은 PC의 브라우저로 주소를 열어도 거부됩니다 |

## 기억되는 것

프로그램은 아래 파일을 `%APPDATA%\ibis_search\` 폴더(파일 탐색기 주소창에 그대로 넣으면 열림)에 저장합니다. 파일을 지우면 그 내용만 처음 상태로 돌아갑니다.

| 파일 | 들어 있는 것 |
|---|---|
| `settings.json` | 화면 모드, 조건 넣는 방식, 체크 상태, 차트 비율, 그림 모드·비율·형식, 끌어 바꾼 크기, 표본 행 수, 메모리 상한, 알림 기준 시간, 예상 시간용 기록 |
| `searches.json` | 저장한 검색 |
| `recipes.json` | 저장한 전처리 구성 |
| `sqls.json` | 저장한 SQL |
| `virtual_tables.json` | 연결마다의 가상 테이블(비밀번호 없음) |
| `dashboards.json` | 저장한 대시보드(그리는 법만, 값과 연결 정보 없음) |
| `metrics_file.json` | 고른 지표 파일의 경로 |
| `llm.json` | AI(LLM) env 파일의 경로(키 없음) |
| `destinations.json` | 보낼 곳. 토큰·주소는 고른 보관 방식대로(암호문, 비움, 환경변수 이름) |
| `slack_bot.json` | Slack 봇 설정(토큰은 보관 방식대로), 허용할 사용자·채널 |
| `ga4.json` | GA4 설정(키 파일 경로, 속성 ID 등. 키 자체는 없음) |
| `uploads.json` | 업로드 기록(저장·적재한 곳, 행, 크기, 범위. 비밀번호 없음) |
| `collections.json` | 저장한 수집 구성(env 파일은 경로만) |
| `limits.json`, `limits_usage.json` | 사용 한도 묶음과 보낸 요청 기록 |
| `browser\` | 수집용 창의 로그인 상태. [로그인 정보 지우기]로 지움 |
| `kafka.json` | 등록한 Kafka(비밀번호 없음) |
| `schedules.json`, `runs.json`, `locks\` | 예약, 실행 기록, 겹쳐 돌지 않게 하는 잠금 |
| `load_tables.json` | 이 프로그램이 적재로 만든 테이블 목록 |
| `usage.json` | 연결한 곳과 아이디, 자주 쓴 검색·SQL·가상 테이블·지표의 사용 횟수(자주 쓴 것을 위로 올리는 데 씀) |
| `table_preps.json` | 테이블별 마지막 전처리 |
| `profile_cache.json`, `data_spec.json` | 테이블별 표본 통계, 데이터 명세서 경로 |
| `recent.json` | 예전 버전의 마지막 연결(처음 실행 때 `usage.json`으로 옮김) |

비밀번호와 저장하지 않은 조건은 기억하지 않습니다. 파일을 덮어쓰기 전에는 `이름.bak`으로 하나 남겨 두고, 파일이 깨지면 그것을 읽습니다.

**PC를 바꿀 때**: 이 폴더를 통째로 새 PC에 복사하면 검색·대시보드·구성이 그대로 옵니다. 단, "암호화해 저장"한 토큰은 새 PC에서 풀 수 없으니 다시 입력하세요.

## DB별 드라이버

회사 DB에 연결할 때 쓰는 주소 모양입니다. 주소와 계정은 보통 DB 담당자에게 받습니다. 필요한 드라이버가 없으면 프로그램이 설치 방법을 알려 줍니다. 주소 뒤에 `?키=값&키=값`을 붙이면 DB별 추가 설정이 됩니다.

| DB | 주소 예 | 따로 설치할 것 |
|---|---|---|
| DuckDB | `duckdb://data.duckdb` | 없음 |
| SQLite | `sqlite://data.db` | 없음 |
| MSSQL | `mssql://host:1433/db` | [ODBC Driver 17/18 for SQL Server](https://learn.microsoft.com/sql/connect/odbc/download-odbc-driver-for-sql-server) |
| PostgreSQL | `postgres://host:5432/db` | 없음 |
| MySQL | `mysql://host:3306/db` | 없음 |
| Oracle | `oracle://host:1521/db` | 없음 |
| ClickHouse | `clickhouse://host:8123/db` | 없음 |
| Trino | `trino://host:8080/catalog/schema` | 없음 |
| Snowflake | `snowflake://계정/데이터베이스/스키마?warehouse=WH` | 없음 |
| BigQuery | `bigquery://프로젝트/데이터셋` | 없음(처음 접속 때 Google 로그인) |
| Databricks | `databricks://?server_hostname=호스트&http_path=경로&access_token=토큰` | 없음 |
| Athena | `athena://?s3_staging_dir=s3://버킷/경로&region_name=ap-northeast-2` | 없음(AWS 자격 증명) |
| Druid, Exasol, Impala, Materialize, RisingWave, SingleStore | `druid://host:8082/druid/v2/sql` 등 | 없음 |
| Spark, Flink | `pyspark://`, `flink://` | [Java](https://adoptium.net/). exe에는 없고 소스로 실행할 때만(`pip install 'ibis-framework[pyspark]'`) |

**예**: 회사 Postgres의 `sales` DB, 서버 `db.company.local` → 주소 `postgres://db.company.local:5432/sales`, 아이디·비밀번호는 칸에 따로 넣습니다(주소에 비밀번호를 쓰지 마세요).

MSSQL은 설치된 ODBC 드라이버 중 최신을 자동으로 고릅니다. 다른 것을 쓰려면 주소 끝에 `?driver=드라이버이름`을 붙입니다. 아이디·비밀번호를 모두 비우면 Windows 로그인으로 접속합니다.
