# 흐름(퍼널)

[← README](../README.md) · [쿼리](query.md) · [분석](analysis.md) · [수집](collect.md) · [연동](integrations.md) · [설정과 참고](settings.md) · [대시보드](dashboard.md)

**한 줄 요약**: 사용자가 정해 둔 단계(방문 → 장바구니 → 결제 …)를 **순서대로** 거쳐 간 사람이 몇 명인지, 어디서 얼마나 빠졌는지 그림과 표로 봅니다. 분석 화면의 **흐름(퍼널)**에서 만들고, 대시보드 카드로도 둘 수 있습니다.

| 말 | 뜻 |
|---|---|
| 사용자 컬럼 | 사람을 구분하는 컬럼(회원 번호, 기기 ID …) |
| 단계 컬럼 | 행동 이름이 들어 있는 컬럼(`방문`, `장바구니`, `결제` …) |
| 시각 컬럼 | 행동이 일어난 날짜·시각 컬럼(날짜나 날짜시간이어야 함) |
| 단계 | 단계 컬럼의 값. 1~10개, 순서가 곧 거치는 순서 |

## 따라 해 보기

1. 분석 화면 → **흐름(퍼널)**을 고르고, 사용자·단계·시각 컬럼을 고릅니다.
2. 단계 칸에 값을 고르거나 써서 **[추가]**합니다(단계 컬럼에서 많이 나온 값이 목록으로 뜹니다). 칩을 **끌어서** 순서를 바꾸고 **×**로 뺍니다. 같은 단계를 두 번 넣을 수는 없습니다.
3. 필요하면 **기간 제한**에 숫자와 단위(분·시간·일)를 씁니다. 비우면 제한이 없습니다.
4. **[구하기]**. 가운데에 그림과 한 줄 설명, 아래에 표가 나옵니다.

## 어떻게 세나요

- 첫 단계의 사용자별 가장 이른 시각부터 시작해, 다음 단계는 **앞 단계 이후**에 한 가장 이른 행동으로 이어 갑니다.
- **중간에 한 다른 행동과 되돌아간 행동은 무시**합니다. 장바구니를 방문보다 먼저 한 행은 세지 않습니다.
- 같은 시각의 두 단계는 도달한 것으로 셉니다.
- **기간 제한**이 있으면 첫 단계 시각부터 그 시간 안(끝 시각 포함)에 도달한 사람만 셉니다.
- 전처리를 적용한 결과 기준이고, 기본은 표본, **[전체로 다시 구하기]**는 테이블 전체입니다. 읽는 컬럼은 사용자·단계·시각 셋뿐입니다.

## 그림과 표

- **그림(생키)**: 단계마다 세로 막대(높이는 사람 수에 비례), 다음 단계로 간 사람은 **초록 띠**, 빠진 사람은 **주황 띠**가 막대 오른쪽에서 아래로 갈라져 내려갑니다. 띠에 마우스를 올리면 사람 수가 보입니다.
- **표**: 단계별 사용자 수 · 다음 단계 전환율 · 처음 대비 비율 · 이탈 수(그 단계에서 다음 단계로 못 간 사람).
- 설명 문장은 구한 숫자에서만 만들고, 첫 단계에 아무도 없으면 그렇게 적습니다.

## 대시보드에 넣기

- 분석 화면의 **[대시보드에 추가]**로 지금 결과를 `흐름` 카드로 넣습니다. 대시보드 화면의 **[카드 추가] → 흐름(퍼널)**로도 만듭니다(테이블, 세 컬럼, 단계를 쉼표로, 기간 제한).
- 최신화와 **[다시 구하기]**는 세 컬럼만 읽어 다시 구합니다. 대시보드의 **기간**을 정하면 시각 컬럼의 날짜가 그 안인 행만 셉니다(비우면 전부).
- 색은 카드의 [색]에서 `단계 막대`·`다음 단계`·`이탈` 이름으로 바꿉니다.
