# 분석 화면

[← README](../README.md) · [쿼리](query.md) · [분석](analysis.md) · [수집](collect.md) · [연동](integrations.md) · [설정과 참고](settings.md)

**한 줄 요약**: 지저분한 데이터를 깨끗하게 정리하고(전처리), 그 데이터가 어떻게 생겼는지 그래프로 살펴보는(분석) 화면입니다. **원본은 바꾸지 않고**, 정리한 결과는 새 파일이나 새 테이블로 따로 저장합니다.

탭은 셋입니다: **전처리**(정리해서 새 파일로), **분석**(분포·관계·그룹·기간별로 살펴보기), **그래프**(만든 그래프 모아 저장).

| 말 | 뜻 |
|---|---|
| 전처리 | 분석 전에 데이터를 다듬는 일. 예: `" 서울 "` → `"서울"`, `"N/A"` → 빈칸 |
| 빈 값 | 아무것도 들어 있지 않은 칸 |
| 표본 | 큰 데이터 대신 일부(기본 5,000행)만 읽어 빠르게 보는 것 |
| 분포 / 상관관계 | 값이 어디에 몰려 있는지 / 한 값이 커질 때 다른 값도 커지는지 |

## 따라 해 보기

**1. 지저분한 고객 명단 정리하기**

`customers.csv`에 이름 앞뒤 공백, 전화번호 칸의 `-`·`N/A`, `20250131` 같은 글자 날짜, 같은 고객 중복이 섞여 있다고 합시다.

1. 첫 화면 **[분석]** → 그 폴더를 연결하고 ① 데이터에서 `customers`를 고릅니다.
2. **[정보]** 탭에 데이터 앞 20행, **[명세서]** 탭에 컬럼마다 요약과 **추천**이 나옵니다. 맞으면 **[추천 모두 적용]**.
   예: 이름 → 앞뒤 공백 지우기, 전화번호 → `-, N/A`를 빈 값으로, 가입일 → 날짜로 바꾸기(`%Y%m%d`)
3. 오른쪽 ⑤ **중복 기준** 에서 `고객ID` → 같은 고객은 하나만 남습니다.
4. **[미리보기]** 로 앞 20행과 "행 수: 전 1,300 → 후 1,280"을 확인합니다.
5. ⑦ **저장** 에서 파일(Parquet·CSV)과 위치를 고르고 **[실행]**.

**2. 주문 금액은 주로 얼마일까? 매장별로는?**

1. 전처리 탭에서 `orders`를 고른 채 위쪽 **[분석]** 탭으로 갑니다.
2. **분포**, 컬럼 `금액` → **[구하기]**: 금액대별 막대(히스토그램)와 최소·평균·최대. [상자 그림]을 누르면 튀는 값이 점으로 보입니다.
3. **그룹 비교**, 그룹 `매장코드`, 집계 `평균`, 값 `금액` → 매장별 평균 금액이 큰 순으로.
4. **시계열 추이**, 날짜 `주문일`, 단위 `월`, 집계 `합계`, 값 `금액` → 월별 매출 선 그래프.
5. 마음에 드는 그래프는 **[그래프에 추가]** → [그래프] 탭에서 [다운로드]로 그림 저장.

## 전처리

![전처리 화면](screen-prep.png)

**쓰는 순서**: ① 테이블 고르기 → 컬럼을 누르면 오른쪽 ③ 컬럼 정리가 열림 → [+ 정리 방법 추가] → 필요하면 ② 행 거르기 ④ 새 컬럼 ⑤ 중복 기준 ⑥ 정렬 → [미리보기] → ⑦ 저장 → [실행].

**자주 쓰는 전처리**

| 하고 싶은 것 | 고를 것 |
|---|---|
| 앞뒤·연속 공백 없애기 | 앞뒤 공백 지우기, 연속 공백을 하나로 |
| `-`, `N/A`를 빈칸으로 | 이 값들을 빈 값으로(`-, N/A`) |
| "1,000원" → 1000 | 글자 찾아 지우기(`원`) → 타입 바꾸기(정수) |
| 글자 날짜를 날짜로 | 타입 바꾸기(날짜) + 형식(`20250131`이면 `%Y%m%d`, `2025-01-31`이면 비워 둠) |
| 대소문자 통일 | 소문자로 |
| `Y` → `완료`처럼 바꾸기 | 값 바꿔 쓰기 |
| 빈칸 채우기·빼기 | 빈 값 처리: 그 행 빼기, 또는 평균·중앙값·가장 흔한 값·앞 행 값으로 채우기 |
| 튀는 값 처리 | 범위 밖 값 처리(빼기 또는 잘라 내기) |
| 연·월·요일 따로 | 날짜에서 뽑기 → `주문일_month` 같은 새 컬럼 |
| 여러 컬럼으로 새 값 | ④ 계산 컬럼: `금액 * 수량`, `iif(금액 >= 10000, '고액', '일반')` |
| 숫자 컬럼 줄이기 | ④ PCA: 컬럼·성분 수를 고르면 `pca_1`…과 설명된 분산 비율 |
| 필요 없는 컬럼 찾기 | 표 위 [뺄 만한 컬럼] → [빼기] |

이 밖에 구간 나누기, 드문 값 묶기, 반올림, 표준화, 패턴(정규식) 바꾸기 등이 있고, 컬럼 이름 바꾸기·복사·빼기도 됩니다.

**알아 둘 점**

- **통계 끄기**: ① 데이터의 [컬럼 통계·추천 구하기]를 끄면 테이블을 골라도 데이터를 읽지 않고 컬럼 이름·타입만 봅니다(요금이 나오는 DB에서).
- **주소로 연결한 DB는 이 PC에서 계산합니다**: 행 거르기까지 한 번 받아 두고 계산은 이 PC가 합니다(① [원격 DB 계산]으로 바꿈).
- **추천은 표본으로 구합니다.** 표본 밖의 이상한 값은 숫자로 바꿀 때 빈칸이 되니 [미리보기]로 확인하세요.
- **중복 기준**: 고른 컬럼이 모두 같은 행을 하나만 남깁니다. [전체 컬럼]은 완전히 같은 행만 지웁니다. [중복 세기]로 몇 행이 빠질지 미리 봅니다.
- **저장**: 파일(Parquet·CSV) 또는 같은 DB의 새 테이블([실행]을 두 번 눌러 확인, 같은 이름이 있으면 만들지 않음).
- **구성 저장**: 고른 전처리 전체를 이름 붙여 저장해 두면 매달 같은 정리를 한 번에 합니다. 같은 테이블을 다시 열면 지난번 전처리를 저절로 채워 줍니다.

### 데이터 명세서

테이블·컬럼 설명을 적어 둔 파일(YAML·JSON)입니다. [명세서] 탭 아래 [명세서 파일]에 경로를 넣고 [읽기]하면 설명이 컬럼마다 보이고, [질문으로 SQL 만들기](query.md#질문으로-sql-만들기)도 이 설명을 써서 더 정확해집니다.

```yaml
tables:
  orders:
    description: 주문 내역
    partition: {column: order_date, recent_days: 3}   # 날짜별 나뉜 테이블이면 최근 3일만 표본으로
    columns:
      status: {description: "주문 상태(Y=완료, N=취소)"}
```

## 분석

![분석 화면](screen-analysis.png)

| 분석 | 이런 질문에 | 고를 것 |
|---|---|---|
| 분포 | 금액은 주로 얼마? 튀는 값은? | 컬럼 하나 |
| 상관관계 | 수량이 많으면 금액도 클까? | 숫자 컬럼 2~12개(히트맵) 또는 X·Y(산점도) |
| 그룹 비교 | 매장마다 평균 금액은? | 그룹 컬럼, 평균·합계·개수, 값 컬럼 |
| 시계열 추이 | 월별 매출이 늘고 있나? | 날짜 컬럼, 일·주·월, 집계, 값 컬럼 |

- 기본은 **표본**(5,000행)으로 구합니다. [전체로 다시 구하기]는 오래 걸리고 요금이 나오는 DB는 비용이 듭니다.
- [지금 전처리를 적용한 결과로]가 켜져 있으면 전처리 탭의 정리를 적용한 데이터로 분석합니다.
- 시계열의 날짜 컬럼은 날짜 타입이어야 합니다. 글자 날짜는 전처리에서 먼저 바꾸세요.
- [그래프] 탭은 카드를 골라 [다운로드]로 그림을 저장합니다(닫으면 사라짐).
