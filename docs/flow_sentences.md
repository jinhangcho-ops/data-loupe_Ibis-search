# 흐름·문장으로 검색하기

[← README](../README.md) · [쿼리](query.md) · [분석](analysis.md) · [수집](collect.md) · [연동](integrations.md) · [설정과 참고](settings.md) · [대시보드](dashboard.md)

**한 줄 요약**: 쿼리 화면 오른쪽 **검색 조건** 패널 위의 **[단계 카드 | 흐름 | 문장]**은 같은 검색 조건을 세 가지 모양으로 보여 줍니다. 하나에서 고치면 다른 보기에서도 그대로입니다.

| 말 | 뜻 |
|---|---|
| 단계 카드 | 데이터 → 조인 → 기간 → 조건 … 칸을 차례로 채우는 기본 보기 |
| 흐름 | 단계를 상자로, 이어지는 순서를 선으로 그린 그림 |
| 문장 | "{무엇}별 {값}의 {집계} 상위 {N}개를 봐요"처럼 빈칸을 채워 묻는 보기 |

보기를 바꿀 때 지금 조건이 다른 모양으로 옮겨 갑니다. 흐름이 단계 카드로 나타낼 수 없는 모양이면 이유를 알려 주고 흐름에 머뭅니다. 집계·지표·차트·카드 상자는 단계 카드에 없으니 흐름에만 남고, 단계 카드를 고치지 않고 돌아오면 그대로 되살아납니다. 흐름·문장 보기에서 **[검색 실행]**을 누르면 단계 카드로 돌아가 검색합니다.

## 흐름 보기

1. **[+ 테이블]** 같은 단추로 상자를 놓습니다. 상자를 누르면 오른쪽 패널에서 내용을 고칩니다(단계 카드와 같은 입력).
2. 상자 오른쪽 점에서 **다른 상자로 끌어** 잇습니다. 순서(테이블 → 이어붙이기 → 조인 → 기간 → 조건 → 계산 → 중복 제거 → 집계·지표 → 차트·카드)에 어긋나거나, 순환이 생기거나, 조인 키의 종류가 다르거나, 다른 연결의 테이블이면 **이을 수 없는 이유를 문장으로** 알려 줍니다.
3. 선 위의 **[+]**는 그 사이에 단계를 끼우고, **[×]**는 이음을 끊습니다. 상자는 끌어서 옮깁니다.
4. 테이블 둘을 조인 상자에 이으면 **공통 키를 찾아** 줍니다. 이름·값 겹침·타입·고유 여부로 점수를 매겨 확실하면 자동으로 고르고, 아니면 상위 3개를 이유와 함께 보여 줘 고르게 합니다. 고른 키는 같은 연결·테이블·컬럼 구성에서 기억합니다. 값 겹침은 표본 기준이고 원격 DB는 값을 새로 읽지 않습니다.
5. **[단계별 행 수 세기]**: 누를 때만, 단계마다 그 단계까지의 행 수를 상자 아래에 보입니다. 원격 DB는 요금이 들 수 있어 확인을 받습니다.
6. 집계·차트·카드 상자를 누르면 거기까지 오는 경로가 밝아집니다. **[경로 밝힘 해제]**로 돌아옵니다.
7. **[최적화 보기]**: 집계가 결과일 때, 조건을 테이블 쪽으로 내리기·쓰지 않는 조인 빼기·조인 전에 먼저 집계하기·쓰는 컬럼만 읽기를 제안합니다. 원래와 바뀐 흐름을 나란히 보이고 바뀐 곳과 이유, 읽는 양의 변화를 알려 줍니다. 두 식을 실제로 돌려 결과가 같으면 **결과 같음 확인됨**, 비교하지 못했으면 **확인 안 됨**입니다. 키가 겹쳐 합계가 부풀 수 있으면 빨간 경고가 뜹니다. 쓸 규칙을 골라 **[이 흐름으로 바꾸기]**를 눌러야 바뀝니다.

## 문장 보기

**[탐색]** 탭의 왼쪽 목록(50개: 48~50번은 좌표 틀, [docs/geo.md](geo.md))에서 문장 틀을 누르면 질문이 더해집니다.

- 빈칸은 **컬럼 칩을 끌어다 놓거나** 빈칸을 눌러 고릅니다. 칩 색은 숫자·날짜·글자를 나타냅니다. 집계·단위·방향·중복 여부는 누르는 단추로 고르고, 컬럼은 `? 뒤 자르기`·`앞 N글자`·`날짜만`·`소문자로` 가공을 붙일 수 있습니다.
- **기간**은 글로 씁니다(`지난 7일`, `2026-01 ~ 2026-03`). 읽은 기간을 바로 아래에 보여 주고, 읽지 못하면 이유를 알려 줍니다.
- 빈칸이 잘못되면 문장 아래에 이유가 나오고, 막힌 문장은 [실행]이 꺼집니다.
- **[실행]**은 서버가 문장을 규칙으로 요청으로 바꿔 돌려 끝난 표를 보여 줍니다(표·차트 전환, 문장 결과 글). 결과가 많으면 처음 1,000행만 보이고 알려 줍니다. 문장은 데이터 값을 밖으로 보내지 않습니다.
- **질문 묶음**: 문장을 여러 개 모아 이름으로 저장하고 다시 엽니다. 묶음 전체가 같은 기간을 쓰게(또는 문장마다 따로) 할 수 있습니다. 다른 테이블에서 열면 같은 이름의 컬럼만 채워지고 비운 칸은 알려 줍니다. **[모두 실행]**은 한꺼번에 돌리고, **[대시보드에 모두 추가]**는 어느 대시보드인지 한 번만 묻고 묶어 집계하는 문장을 차트 카드로 넣습니다(행을 보는 문장은 건너뜁니다).

**[지표]** 탭은 지표 틀 15개로 **내 지표**를 만듭니다. 지표는 지금 연결의 테이블에 묶이고, 같은 테이블에서는 이름이 겹칠 수 없습니다. 다른 테이블의 지표는 쓰지 못하고 **[이 테이블에 맞춰 복사]**로 컬럼 짝을 골라 새로 만듭니다. 다른 지표를 쓰는 지표는 초록(있음)·빨강(없음) 칩으로 보이고, 정의를 고치면 영향받는 지표·카드를 먼저 알립니다. 테이블 구조가 바뀌면 "쓸 수 없음"과 이유가 붙습니다. 아래의 **지표 사전** 자리는 별도 화면이 채웁니다.

## 조건에 쓸 수 있는 것

조건 연산자에 `ends 김`(…로 끝남)이 더해졌습니다. `like`(포함)·`starts`(시작)와 같이 글자 컬럼에 씁니다. 컬럼 이름에 공백이 있어도 조건·정렬에 쓸 수 있고, `in` 값은 따옴표 안의 쉼표를 나누지 않습니다(`in '서울, 강남', 부산`).

## 알아 둘 것

- 흐름의 계산 상자는 단계 카드와 같은 한 줄 글로 씁니다. 날짜 맞춤(일·주·월) 제안은 글로만 알려 주고 자동으로 넣지 않습니다.
- 같은 테이블을 서로 잇는 자기 조인은 단계 카드로 옮길 때 막힐 수 있습니다. 이유가 화면에 나옵니다.
- 흐름을 최적화하면 쓰는 컬럼만 정한 테이블이 생겨 단계 카드로 나타낼 수 없습니다. 흐름에서 계속 쓰세요.
